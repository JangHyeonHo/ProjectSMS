## 회원가입 / 로그인 플로우

### 사장/매니저/직원
1. 사장이 테넌트(가게) 가입 → 가게 정보 입력
2. 사장이 직원 계정 초대(이메일/전화번호) → 직원 초기 비밀번호 설정
3. 로그인: 아이디(또는 이메일/전화번호) + 비밀번호
4. 2FA는 추후 검토 (`07-open-questions.md`)

### 고객
1. 가입 방식(검토 필요): 전화번호 인증 / 소셜 로그인(카카오·네이버)
2. 포인트/쿠폰은 가입 고객에게만 제공
3. QR 주문은 비회원도 가능하되 포인트 적립은 불가

## 미정 사항
- 매니저의 권한 범위를 어디까지 사장이 위임 가능하게 할지
- 직원 권한을 가게별로 얼마나 세분화할지
- 고객 로그인 방식(전화/소셜/이메일) 선택
- 2FA 적용 대상
