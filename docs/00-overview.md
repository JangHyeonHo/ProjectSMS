# 00. 프로젝트 개요

## 프로젝트 이름

**ProjectSMS** (Store Management System) — 추후 정식 서비스명 결정 필요

## 한 줄 소개

**일반 음식점 사장이 주문·결제·재고·직원·예약·고객을 하나의 시스템에서 관리할 수 있는 멀티테넌트 SaaS형 가게 관리 시스템**

## 비전 / 목표

- 소상공인 음식점이 복잡한 POS·예약·재고·인사 시스템을 **하나의 통합 플랫폼**에서 사용할 수 있도록 한다.
- 가게마다 운영 방식이 다른 점을 고려해, 메뉴 구성·테이블 레이아웃·권한 등을 **유연하게 커스터마이즈** 할 수 있게 한다.
- 사장·직원·고객이 각자 역할에 맞는 인터페이스를 통해 시스템에 접근하도록 한다.

## 타겟 사용자

| 구분 | 설명 |
|------|------|
| **사장 (관리자)** | 가게를 운영하는 주체. 매출·직원·재고·메뉴·예약 전체를 관리. |
| **매니저** | 사장 위임 관리자. 일부 권한 제한. |
| **직원 (홀)** | 주문 접수, 결제, 테이블 관리, 예약 처리. |
| **직원 (주방)** | KDS로 주문 확인, 조리 완료 처리. |
| **고객** | QR 주문, 예약, 포인트/쿠폰 사용, 마케팅 알림 수신. |

## 플랫폼

- **웹**: 사장/매니저/직원용 관리자 콘솔, KDS 화면, 고객용 QR 메뉴
- **모바일 앱**: 사장용 모니터링 앱, 고객용 앱(포인트/쿠폰/알림)

## 배포 형태

**멀티테넌트 SaaS** — 여러 음식점(테넌트)이 한 시스템 위에서 각자 독립적으로 사용. 데이터는 테넌트 단위로 격리.

## 지원 언어

- **한국어** 단일 지원

## 핵심 범위 (Scope)

### 포함 (In-scope)
- 주문/POS, QR 주문, 메뉴 관리, 테이블 관리
- 재고/식자재 관리, 직원/인사/스케줄, 예약
- 주방 KDS·프린터, 결제(현금/카드/간편결제)
- 통계/분석 대시보드, 고객앱(포인트/쿠폰/마케팅)

### 제외 (Out-of-scope, 후순위)
- 배달/포장은 외부 배달앱 연동 수준만
- 회계/세무 프로그램 연동(추후 검토)
- 프랜차이즈 본사↔가맹점 구조(추후 검토)

## 용어집 (Glossary)

| 용어 | 설명 |
|------|------|
| **테넌트 (Tenant)** | 시스템을 사용하는 개별 가게(또는 사업자) 단위 |
| **스토어 (Store)** | 실제 운영되는 매장. 한 테넌트가 여러 스토어를 가질 수 있음 |
| **POS** | Point of Sale, 주문·결제를 처리하는 시스템 |
| **KDS** | Kitchen Display System, 주방에서 주문을 확인하는 화면 |
| **QR 주문** | 테이블 QR을 스캔해 고객 스마트폰으로 직접 주문하는 방식 |
| **SaaS** | Software as a Service, 구독형 서비스로 제공되는 소프트웨어 |
| **MVP** | Minimum Viable Product, 최소 기능 제품 |
