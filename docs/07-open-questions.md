# 07. 미정 사항 & 추가 논의 필요 항목

각 기능 문서의 TBD 항목을 한곳에 모아, 빠뜨림 없이 결정을 추적합니다.

## 🔴 Phase 0에서 먼저 결정 필요 (Critical)

### 기술 스택
- [ ] **프론트엔드**: React / Vue / Next.js / SvelteKit / 기타?
- [ ] **백엔드**: Node.js(Nest/Express) / Spring / Django / FastAPI / Go / 기타?
- [ ] **데이터베이스**: PostgreSQL / MySQL / 기타?
- [ ] **캐시/실시간**: Redis / 기타?
- [ ] **인프라**: AWS / GCP / NCP / 온프레미스?
- [ ] **모바일**: 네이티브(iOS+Android) vs React Native vs Flutter vs PWA?

### 핵심 아키텍처
- [ ] 멀티테넌트 격리 수준: 공유 DB + 테넌트ID / 스키마 분리 / DB 분리
- [ ] 실시간 통신: WebSocket / SSE / Polling
- [ ] POS 오프라인 모드 지원 범위

### 비즈니스
- [ ] 서비스 이름/브랜딩 확정
- [ ] 요금제/과금 방식(월 구독 / 매출 연동 / 무료+유료옵션)
- [ ] 목표 첫 고객/베타 가게

## 🟡 Phase 1~2 전에 결정 필요

### 하드웨어 / 연동
- [ ] POS 단말 기종(태블릿 모델, 전용 단말)
- [ ] 영수증 프린터 모델·통신(USB/LAN/블루투스)
- [ ] 주방 프린터 분리 여부
- [ ] KDS 단말(태블릿 거치형 vs 전용 디스플레이)
- [ ] 바코드 스캐너 연동 필요 여부

### 결제 연동
- [ ] 카드 결제: VAN사 선정, 단말기 모델
- [ ] 간편결제 PG 선정(토스페이먼츠 / 포트원 / NHN KCP / KG이니시스)
- [ ] 현금영수증 / 세금계산서 자동 발급 범위
- [ ] 부분 환불 / 분할결제 정책

### 인증/보안
- [ ] 고객 로그인 방식(전화번호 / 소셜 / 이메일)
- [ ] 2FA 적용 대상
- [ ] 개인정보 보관 기간 정책

## 🟢 Phase 3+ 에서 결정 가능

### 메뉴/재고
- [ ] 다중 가격(일반/회원/VIP) 지원 여부
- [ ] 메뉴 가격 변경 이력 추적 여부
- [ ] 레시피 입력을 필수 vs 선택으로 할지
- [ ] 재고 실시간 차감 vs 배치 차감
- [ ] 다점포 재고 공유 여부
- [ ] 업종별 메뉴 템플릿 제공 여부

### 인사/근무
- [ ] 급여 자동 계산 범위(단순 집계 vs 세금·수당 포함)
- [ ] 출퇴근 체크 방식(비밀번호/QR/위치)
- [ ] 주휴수당·연장근로수당 법정 계산 포함 여부

### 예약
- [ ] 네이버/카카오 예약 API 승인 및 연동 방식
- [ ] 예약금 결제 정책
- [ ] 워크인/웨이팅 통합 여부

### 고객앱 / 마케팅
- [ ] 고객앱: 가게별 전용 앱 vs 플랫폼 통합 앱
- [ ] 포인트 적립률: 고정 vs 가게별 설정
- [ ] 알림톡 발송 비용 부담 주체
- [ ] 개인정보보호법 준수(수신동의, 보관) 상세

### 테이블/QR
- [ ] QR 세션 유효기간
- [ ] 같은 테이블 다중 주문자 장바구니 공유
- [ ] 비회원 QR 주문자 연락처 수집
- [ ] 선불/후불 모드 전환 단위

### 기타
- [ ] 오프라인 모드 범위
- [ ] 이미지 저장소 용량 제한
- [ ] 리포트 정기 이메일 발송
- [ ] 예측 분석(AI) 포함 여부
- [ ] 매니저 권한 위임 범위
