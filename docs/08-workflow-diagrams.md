# 08. 업무 워크플로우 다이어그램

비개발자(사장/직원/고객) 관점에서 실제 업무 흐름을 정리한 문서입니다.
**Swim Lane 방식** — 각 역할이 수평 레인으로 나뉘어, 누가 무엇을 하는지와 역할 간 업무 이동을 한눈에 파악할 수 있습니다.

> 시각적으로 렌더링된 버전은 Artifact를 참조하세요.
