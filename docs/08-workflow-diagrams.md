# 08. 업무 워크플로우 다이어그램

비개발자(사장/직원/고객) 관점에서 실제 업무 흐름을 정리한 문서입니다.

---

## 1. 전체 흐름: 손님 방문부터 퇴장까지

가게에서 일어나는 전체 흐름을 한눈에 보여줍니다.

```mermaid
flowchart TD
    A[손님 입장] --> B{예약 손님?}
    B -- 예 --> C[예약 확인 → 배정 테이블 안내]
    B -- 아니오 --> D{빈 테이블 있음?}
    D -- 예 --> E[테이블 안내]
    D -- 아니오 --> F[대기 등록]
    F --> G[자리 생기면 호출]
    G --> E
    C --> E

    E --> H{주문 방식}
    H -- 직원 주문 --> I[직원이 POS로 주문 접수]
    H -- QR 주문 --> J[손님이 QR 스캔 → 메뉴 선택 → 주문]

    I --> K[주문이 주방으로 전송]
    J --> K

    K --> L[주방에서 조리]
    L --> M[조리 완료 → 홀 직원 알림]
    M --> N[서빙]

    N --> O{추가 주문?}
    O -- 예 --> H
    O -- 아니오 --> P[결제 요청]

    P --> Q{결제 수단}
    Q -- 현금 --> R[현금 수령 → 거스름돈]
    Q -- 카드 --> S[카드 단말기 결제]
    Q -- 간편결제 --> T[QR/바코드 스캔 결제]

    R --> U[영수증 발행]
    S --> U
    T --> U

    U --> V{포인트 적립?}
    V -- 예 --> W[포인트 적립 처리]
    V -- 아니오 --> X[테이블 정리]
    W --> X

    X --> Y[손님 퇴장]
```

## 2. 직원 POS 주문 처리

직원이 POS를 사용해 주문을 받는 상세 흐름입니다.

```mermaid
flowchart TD
    A[직원: POS 메인화면] --> B[테이블 배치도에서 테이블 선택]
    B --> C[주문 화면 진입]
    C --> D[카테고리/검색으로 메뉴 선택]
    D --> E{옵션 있음?}
    E -- 예 --> F[옵션 선택: 맵기/사이즈/토핑 등]
    E -- 아니오 --> G[수량 입력]
    F --> G
    G --> H[주문 리스트에 추가]

    H --> I{더 주문할 메뉴?}
    I -- 예 --> D
    I -- 아니오 --> J{요청사항?}
    J -- 예 --> K[메모 입력: 알레르기, 요청 등]
    J -- 아니오 --> L[주문 전송 버튼]
    K --> L

    L --> M[주방 KDS에 표시 + 프린터 출력]
    M --> N[테이블 상태: 이용중으로 변경]
    N --> O[POS 메인으로 복귀]
```

## 3. QR 셀프 주문 (고객 시점)

고객이 QR을 스캔해서 직접 주문하는 흐름입니다.

```mermaid
flowchart TD
    A[손님: 테이블 QR 스캔] --> B[스마트폰 브라우저에 메뉴 페이지 열림]
    B --> C[메뉴 카테고리 탐색]
    C --> D[메뉴 선택 → 사진/설명 확인]
    D --> E{옵션 선택}
    E --> F[수량 조절]
    F --> G[장바구니에 담기]

    G --> H{더 담을 메뉴?}
    H -- 예 --> C
    H -- 아니오 --> I[장바구니 확인]

    I --> J{요청사항?}
    J -- 예 --> K[메모 입력]
    J -- 아니오 --> L[주문하기 버튼]
    K --> L

    L --> M{결제 모드}
    M -- 후불 --> N[주문 접수 완료 화면]
    M -- 선불 --> O[간편결제 선택]
    O --> P[결제 완료 → 주문 확인 화면]

    N --> Q[주방으로 주문 전달]
    P --> Q

    Q --> R[주문 상태 실시간 확인 가능]
    R --> S{추가 주문?}
    S -- 예 --> C
    S -- 아니오 --> T[식사]
```

## 4. 주방 조리 흐름 (KDS)

주방 직원이 KDS 화면으로 주문을 확인하고 조리하는 흐름입니다.

```mermaid
flowchart TD
    A[주문 들어옴] --> B[KDS 화면에 새 주문 카드 표시]
    B --> C[알림음 울림]
    C --> D[주방 직원: 주문 내용 확인]
    D --> E[테이블번호 / 메뉴 / 옵션 / 요청사항]

    E --> F[조리 시작 버튼 터치]
    F --> G[카드 상태: 조리중으로 변경]
    G --> H[경과 시간 표시 시작]

    H --> I[조리 진행]
    I --> J[조리 완료 버튼 터치]
    J --> K[홀 직원에게 서빙 알림]
    K --> L[KDS에서 해당 카드 사라짐]

    style B fill:#FFE0B2
    style G fill:#FFF9C4
    style L fill:#C8E6C9
```

## 5. 결제 흐름

결제 처리의 상세 흐름입니다.

```mermaid
flowchart TD
    A[손님: 결제 요청] --> B[직원: POS에서 해당 테이블 선택]
    B --> C[주문 내역 확인]

    C --> D{할인/혜택 적용?}
    D -- 쿠폰 --> E[쿠폰 스캔/번호 입력]
    D -- 포인트 --> F[포인트 차감 금액 입력]
    D -- 수동 할인 --> G[할인 사유/금액 입력 - 권한 필요]
    D -- 없음 --> H[최종 금액 확인]
    E --> H
    F --> H
    G --> H

    H --> I{결제 수단 선택}
    I -- 현금 --> J[받은 금액 입력 → 거스름돈 표시]
    I -- 카드 --> K[카드 단말기 → 결제 처리]
    I -- 간편결제 --> L[QR/바코드 스캔]
    I -- 분할 결제 --> M[수단별 금액 분배 → 각각 결제]

    J --> N{영수증}
    K --> N
    L --> N
    M --> N

    N -- 지류 --> O[프린터 출력]
    N -- 전자 --> P[SMS/카카오톡 발송]
    N -- 현금영수증 --> Q[국세청 연동 발급]

    O --> R[포인트 적립 처리]
    P --> R
    Q --> R

    R --> S[테이블 상태: 빈자리로 변경]
    S --> T[매출 자동 집계]
```

## 6. 예약 흐름

다양한 경로의 예약이 통합 관리되는 흐름입니다.

```mermaid
flowchart TD
    subgraph 예약경로
        A1[전화 예약]
        A2[고객앱/웹 예약]
        A3[네이버 예약]
        A4[카카오 예약]
    end

    A1 --> B[직원이 POS에 수동 등록]
    A2 --> C[시스템 자동 접수]
    A3 --> D[API 연동 → 자동 동기화]
    A4 --> D

    B --> E[통합 예약 캘린더]
    C --> E
    D --> E

    E --> F[예약 확정 → 알림 발송]
    F --> G[SMS/카카오톡: 예약 확인 메시지]

    G --> H[방문 전일 리마인드 발송]
    H --> I{당일: 손님 방문?}

    I -- 예 --> J[예약 확인 → 테이블 안내]
    J --> K[예약 상태: 방문완료]

    I -- 아니오 --> L{연락 가능?}
    L -- 예 --> M[연락 → 취소/변경 확인]
    L -- 아니오 --> N[노쇼 처리]
    N --> O[노쇼 기록 저장]

    M -- 취소 --> P[예약 취소 처리]
    M -- 변경 --> Q[예약 변경 → 캘린더 업데이트]
```

## 7. 재고/식자재 관리 흐름

식자재 입고부터 자동 차감, 발주까지의 흐름입니다.

```mermaid
flowchart TD
    subgraph 입고
        A1[거래처에서 식자재 도착]
        A1 --> A2[입고 수량/단가/유통기한 입력]
        A2 --> A3[재고 수량 증가]
    end

    subgraph 자동차감
        B1[손님 주문 접수]
        B1 --> B2[메뉴의 레시피 확인]
        B2 --> B3[필요 식자재 자동 차감]
        B3 --> B4{재고 부족?}
        B4 -- 예 --> B5[사장/매니저에게 알림]
        B4 -- 아니오 --> B6[정상 처리]
    end

    subgraph 발주
        C1[재고 부족 알림 수신]
        C1 --> C2[발주서 작성]
        C2 --> C3[거래처별 품목/수량 확인]
        C3 --> C4[발주 전송: 메일/출력]
        C4 --> C5[발주 상태: 대기중]
        C5 --> C6[거래처 납품 → 입고 처리]
    end

    subgraph 유통기한
        D1[매일 자동 체크]
        D1 --> D2{임박 식자재?}
        D2 -- 예 --> D3[알림: 유통기한 임박 품목]
        D3 --> D4{사용 가능?}
        D4 -- 예 --> D5[우선 사용 권장]
        D4 -- 아니오 --> D6[폐기 처리 기록]
    end

    subgraph 재고실사
        E1[정기 실사일]
        E1 --> E2[실제 수량 카운트]
        E2 --> E3[전산 재고와 비교]
        E3 --> E4{차이 있음?}
        E4 -- 예 --> E5[차이 조정 + 원인 메모]
        E4 -- 아니오 --> E6[실사 완료]
    end
```

## 8. 직원 출퇴근 / 스케줄 흐름

직원 근무 관리의 전체 흐름입니다.

```mermaid
flowchart TD
    subgraph 스케줄작성
        A1[사장/매니저: 주간 스케줄 작성]
        A1 --> A2[직원별 요일/시간 배정]
        A2 --> A3[스케줄 확정 → 직원에게 알림]
    end

    subgraph 출퇴근
        B1[직원 출근]
        B1 --> B2[출근 체크: POS/모바일에서 기록]
        B2 --> B3[근무 시작]
        B3 --> B4{휴게시간?}
        B4 -- 예 --> B5[휴게 시작/종료 기록]
        B5 --> B3
        B4 --> B6[퇴근 시간]
        B6 --> B7[퇴근 체크]
        B7 --> B8[근무시간 자동 계산]
    end

    subgraph 집계
        C1[월말]
        C1 --> C2[직원별 근무시간 집계]
        C2 --> C3[지각/조퇴/결근 표시]
        C3 --> C4[급여 정산 참고자료 출력]
    end

    subgraph 스케줄변경
        D1[직원: 스케줄 변경 요청]
        D1 --> D2[사장/매니저: 승인/거절]
        D2 -- 승인 --> D3[스케줄 업데이트]
        D2 -- 거절 --> D4[원래 스케줄 유지]
    end
```

## 9. 고객 포인트 / 쿠폰 흐름

고객이 포인트를 적립하고 쿠폰을 사용하는 흐름입니다.

```mermaid
flowchart TD
    subgraph 포인트적립
        A1[결제 완료]
        A1 --> A2{회원 고객?}
        A2 -- 예 --> A3[결제 금액 × 적립률 = 포인트 적립]
        A2 -- 아니오 --> A4[비회원: 적립 불가 안내]
        A4 --> A5{가입 유도}
        A5 -- 가입 --> A6[회원가입 → 적립]
        A5 -- 거부 --> A7[다음에]
    end

    subgraph 포인트사용
        B1[결제 시 포인트 사용 요청]
        B1 --> B2[보유 포인트 확인]
        B2 --> B3[사용할 포인트 입력]
        B3 --> B4[결제 금액에서 차감]
    end

    subgraph 쿠폰발행
        C1[사장: 쿠폰 생성]
        C1 --> C2[종류: 금액할인 / 퍼센트 / 메뉴증정]
        C2 --> C3[조건: 최소금액, 유효기간, 대상]
        C3 --> C4{발행 방식}
        C4 -- 자동 --> C5[가입축하/생일/재방문 자동 발급]
        C4 -- 수동 --> C6[대상 고객 선택 → 발송]
    end

    subgraph 쿠폰사용
        D1[결제 시 쿠폰 제시]
        D1 --> D2[쿠폰 스캔/번호 입력]
        D2 --> D3{유효한 쿠폰?}
        D3 -- 예 --> D4{사용 조건 충족?}
        D4 -- 예 --> D5[할인 적용]
        D4 -- 아니오 --> D6[조건 미충족 안내]
        D3 -- 아니오 --> D7[만료/사용완료 안내]
    end

    subgraph 마케팅알림
        E1[사장: 마케팅 발송 설정]
        E1 --> E2[대상 선택: 전체/단골/미방문/생일자]
        E2 --> E3[내용 작성: 신메뉴/이벤트/할인]
        E3 --> E4[발송: 푸시/SMS/카카오톡]
        E4 --> E5[수신 동의 고객에게만 전달]
    end
```

## 10. 가게 하루 운영 흐름 (오픈 → 마감)

사장/매니저 관점에서 하루 전체 운영 흐름입니다.

```mermaid
flowchart TD
    subgraph 오픈준비
        A1[출근 → 시스템 로그인]
        A1 --> A2[오늘 예약 현황 확인]
        A2 --> A3[오늘 직원 스케줄 확인]
        A3 --> A4[재고 부족 알림 확인]
        A4 --> A5{부족 품목?}
        A5 -- 예 --> A6[긴급 발주 or 메뉴 품절 처리]
        A5 -- 아니오 --> A7[메뉴판 최종 점검]
        A6 --> A7
        A7 --> A8[영업 시작]
    end

    subgraph 영업중
        B1[영업 시작]
        B1 --> B2[손님 맞이 → 주문 → 조리 → 서빙 → 결제]
        B2 --> B3[중간 확인: 매출 현황]
        B3 --> B4[중간 확인: 재고 상태]
        B4 --> B5[예약 손님 도착 관리]
        B5 --> B2
    end

    subgraph 마감
        C1[영업 종료]
        C1 --> C2[오늘 매출 확인]
        C2 --> C3[현금 시재 확인]
        C3 --> C4[일일 마감 리포트]
        C4 --> C5[재고 점검: 내일 부족 품목?]
        C5 --> C6{발주 필요?}
        C6 -- 예 --> C7[발주서 작성]
        C6 -- 아니오 --> C8[마감 완료]
        C7 --> C8
    end

    A8 --> B1
    B2 --> C1
```

## 11. 메뉴 관리 흐름

메뉴를 등록하고 운영하는 흐름입니다.

```mermaid
flowchart TD
    subgraph 메뉴등록
        A1[사장: 새 메뉴 등록]
        A1 --> A2[기본 정보: 이름, 가격, 설명]
        A2 --> A3[사진 업로드]
        A3 --> A4[카테고리 분류]
        A4 --> A5{옵션 필요?}
        A5 -- 예 --> A6[옵션 그룹 설정: 맵기/사이즈/토핑]
        A5 -- 아니오 --> A7{레시피 등록?}
        A6 --> A7
        A7 -- 예 --> A8[식자재 + 소요량 매핑]
        A7 -- 아니오 --> A9[메뉴 저장 → 즉시 노출]
        A8 --> A9
    end

    subgraph 메뉴운영
        B1[영업 중 품절 발생]
        B1 --> B2[품절 토글 ON]
        B2 --> B3[POS + QR메뉴에 품절 표시]
        B3 --> B4[재입고 시 품절 해제]
    end

    subgraph 시간대메뉴
        C1[런치 전용 메뉴 설정]
        C1 --> C2[노출 시간대: 11:00~14:00]
        C2 --> C3[해당 시간에만 주문 가능]
    end

    subgraph 가격변경
        D1[가격 인상/할인]
        D1 --> D2[메뉴별 or 카테고리 일괄]
        D2 --> D3[변경 즉시 반영]
    end
```

## 12. 테이블 관리 흐름

테이블의 실시간 상태 변화 흐름입니다.

```mermaid
flowchart TD
    A[테이블 상태: 빈자리] --> B[손님 착석]
    B --> C[테이블 상태: 이용중]
    C --> D[주문 접수 → 조리 → 서빙]

    D --> E{추가 주문?}
    E -- 예 --> D
    E -- 아니오 --> F[결제]

    F --> G[테이블 상태: 청소중]
    G --> H[직원: 테이블 정리 완료]
    H --> A

    I[예약 시간 임박] --> J[테이블 상태: 예약]
    J --> K{예약 손님 도착?}
    K -- 예 --> B
    K -- 노쇼 --> L[테이블 상태 해제 → 빈자리]
    L --> A

    M{합석 요청} --> N[테이블 2개 이상 합치기]
    N --> O[통합 주문으로 관리]
    O --> P[결제 시 분리 가능: 더치페이]
```
