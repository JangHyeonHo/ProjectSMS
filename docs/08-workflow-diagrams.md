# 08. 업무 워크플로우 다이어그램

비개발자(사장/직원/고객) 관점에서 실제 업무 흐름을 정리한 문서입니다.
Mermaid Sequence Diagram을 **Swim Lane** 형태로 사용하여, 각 역할 간 업무 이동을 시각적으로 보여줍니다.

---

## 1. 전체 흐름: 손님 방문 → 퇴장

```mermaid
sequenceDiagram
    actor 손님
    participant 홀직원
    participant 주방
    participant 시스템

    손님->>홀직원: 입장
    홀직원->>시스템: 예약 확인 / 빈 테이블 조회
    시스템-->>홀직원: 배정 가능 테이블 안내
    홀직원->>손님: 테이블 안내 & 착석
    시스템->>시스템: 테이블 상태 → 이용중

    rect rgb(240, 248, 255)
        Note over 손님, 시스템: 주문 (택1)
        alt 직원 주문
            손님->>홀직원: 구두로 메뉴 선택
            홀직원->>시스템: POS에서 주문 입력
        else QR 셀프 주문
            손님->>시스템: QR 스캔 → 메뉴 선택 → 주문
        end
    end

    시스템->>주방: 주문 전송 (KDS + 프린터)
    시스템->>시스템: 개수 품목(병/캔) 자동 차감
    주방->>주방: 조리
    주방->>시스템: KDS에서 [완료] 터치
    시스템->>홀직원: 서빙 알림
    홀직원->>손님: 서빙

    Note over 손님: 식사 (추가 주문 가능)

    손님->>홀직원: 결제 요청
    홀직원->>시스템: 할인 적용 + 결제 처리
    시스템-->>홀직원: 영수증 발행
    홀직원->>손님: 영수증 전달
    시스템->>시스템: 포인트 적립 + 매출 집계
    홀직원->>시스템: 테이블 정리 완료
    시스템->>시스템: 테이블 상태 → 빈자리
```

## 2. 직원 POS 주문 처리

```mermaid
sequenceDiagram
    actor 손님
    participant 홀직원
    participant POS
    participant 주방

    손님->>홀직원: 메뉴 주문 (구두)
    홀직원->>POS: 테이블 선택
    POS-->>홀직원: 주문 화면 표시
    홀직원->>POS: 카테고리/검색 → 메뉴 선택
    홀직원->>POS: 옵션 선택 (맵기/사이즈/토핑)
    홀직원->>POS: 수량 입력
    홀직원->>POS: 요청사항 메모 입력

    Note over 홀직원, POS: 더 주문할 메뉴 있으면 반복

    홀직원->>POS: 주문 전송 버튼
    POS->>주방: KDS에 주문 카드 표시
    POS->>주방: 주방 프린터 주문서 출력
    POS->>POS: 테이블 상태 → 이용중
```

## 3. QR 셀프 주문

```mermaid
sequenceDiagram
    actor 손님
    participant 시스템
    participant 주방
    participant POS

    손님->>시스템: 테이블 QR 스캔
    시스템-->>손님: 테이블 식별 → 메뉴 페이지 로드

    손님->>손님: 카테고리 탐색 → 메뉴 선택
    손님->>손님: 사진/설명 확인 → 옵션 선택
    손님->>손님: 장바구니에 담기

    Note over 손님: 더 담을 메뉴 있으면 반복

    손님->>손님: 장바구니 확인 + 요청사항 메모

    alt 후불 모드 (기본)
        손님->>시스템: 주문하기
        시스템-->>손님: 주문 접수 완료 화면
    else 선불 모드
        손님->>시스템: 주문하기 + 간편결제
        시스템-->>손님: 결제 완료 + 주문 확인
    end

    시스템->>주방: KDS에 주문 카드 표시
    시스템->>POS: POS에 주문 반영
    주방->>주방: 조리 시작
    시스템-->>손님: 주문 상태 실시간 업데이트
    주방->>시스템: 조리 완료
    시스템-->>손님: 조리 완료 알림
```

## 4. 주방 조리 흐름 (KDS)

```mermaid
sequenceDiagram
    participant POS/QR as POS · QR
    participant KDS
    actor 주방직원
    participant 홀화면 as 홀 · 사장 화면

    POS/QR->>KDS: 새 주문 도착
    KDS->>KDS: 주문 카드 표시 + 알림음
    Note over KDS: 테이블번호 · 메뉴 · 옵션 · 요청사항
    KDS->>KDS: 경과시간 표시 시작 (참고용, 경고 없음)
    POS/QR->>홀화면: "주문 후 N분 경과" 표시 시작

    주방직원->>주방직원: 위에서부터 순서대로 조리

    Note over 홀화면: 오래 걸리는 주문은 홀에서 확인

    주방직원->>KDS: [완료] 터치 (터치는 이것 한 번만)
    KDS->>KDS: 카드 제거
    KDS->>홀화면: 서빙 알림
    홀화면->>홀화면: 홀 직원 음식 서빙
```

## 5. 결제 처리

```mermaid
sequenceDiagram
    actor 손님
    participant 홀직원
    participant POS
    participant PG as PG · 단말기

    손님->>홀직원: 결제 요청
    홀직원->>POS: 해당 테이블 선택 → 주문 내역 확인

    rect rgb(255, 248, 240)
        Note over 홀직원, POS: 할인/혜택 적용 (해당 시)
        alt 쿠폰
            홀직원->>POS: 쿠폰 스캔 / 번호 입력
        else 포인트
            홀직원->>POS: 사용할 포인트 입력
        else 수동 할인
            홀직원->>POS: 할인 사유 + 금액 (매니저 이상 권한)
        end
        POS->>POS: 최종 금액 계산
    end

    홀직원->>손님: 최종 금액 안내

    alt 현금
        손님->>홀직원: 현금 지불
        홀직원->>POS: 받은 금액 입력
        POS-->>홀직원: 거스름돈 계산
    else 카드
        손님->>PG: 카드 태그/삽입
        PG-->>POS: 승인 완료
    else 간편결제
        손님->>PG: 카카오/네이버페이 QR 스캔
        PG-->>POS: 결제 완료
    else 분할 결제
        홀직원->>POS: 수단별 금액 분배
        Note over POS, PG: 각각 결제 처리
    end

    POS->>홀직원: 영수증 발행 (지류/전자/현금영수증)
    홀직원->>손님: 영수증 전달
    POS->>POS: 포인트 적립 + 매출 집계 + 테이블 해제
```

## 6. 예약 관리

```mermaid
sequenceDiagram
    actor 고객
    participant 외부플랫폼 as 네이버 · 카카오
    participant 직원
    participant 시스템

    rect rgb(240, 248, 255)
        Note over 고객, 시스템: 예약 접수 (3가지 경로)
        alt 전화 예약
            고객->>직원: 전화로 예약 요청
            직원->>시스템: 수동 등록 (이름/연락처/인원/일시)
        else 온라인 예약
            고객->>시스템: 앱/웹에서 직접 예약
            시스템->>시스템: 자동 접수
        else 외부 플랫폼
            고객->>외부플랫폼: 네이버/카카오에서 예약
            외부플랫폼->>시스템: API 연동 → 자동 동기화
        end
    end

    시스템->>시스템: 통합 예약 캘린더에 등록
    시스템->>고객: 예약 확정 SMS/카카오톡 발송

    Note over 시스템: 방문 전일

    시스템->>고객: 리마인드 메시지 자동 발송

    Note over 시스템: 당일

    alt 손님 방문
        고객->>직원: 도착
        직원->>시스템: 예약 확인 → 테이블 안내
        시스템->>시스템: 상태 → 방문완료
    else 노쇼
        직원->>고객: 연락 시도
        alt 취소/변경
            직원->>시스템: 예약 취소 or 변경
        else 연락 불가
            직원->>시스템: 노쇼 처리
            시스템->>시스템: 노쇼 기록 저장
        end
    end
```

## 7. 재고 / 식자재 관리

```mermaid
sequenceDiagram
    participant 거래처
    actor 사장 as 사장 · 매니저
    participant 시스템

    rect rgb(240, 255, 245)
        Note over 거래처, 시스템: 입고
        거래처->>사장: 식자재 납품
        사장->>시스템: 입고 등록 (품목/수량/단가/유통기한)
        시스템->>시스템: 재고 수량 증가
    end

    rect rgb(255, 248, 240)
        Note over 거래처, 시스템: 차감 (2가지 방식 병행)
        alt 개수 단위 품목 (병/캔 음료 등)
            시스템->>시스템: 주문 접수 시 즉시 자동 차감
        else 일반 식자재 (야채/육류/소스 등)
            사장->>시스템: 일일 마감 시 실제 사용량 확인 후 수동 차감
            Note right of 시스템: 레시피 기반 예상량은 참고값으로 표시
        end
        alt 재고 부족
            시스템->>사장: 최소 기준 이하 알림
        end
    end

    rect rgb(240, 245, 255)
        Note over 거래처, 시스템: 발주
        사장->>시스템: 발주서 작성 (거래처별 품목/수량)
        사장->>거래처: 발주 전송 (메일/인쇄)
        시스템->>시스템: 발주 상태 추적
        거래처->>사장: 납품 → 입고 처리 (순환)
    end

    rect rgb(255, 255, 240)
        Note over 거래처, 시스템: 유통기한 & 실사
        시스템->>사장: 매일 유통기한 임박 품목 알림
        alt 사용 가능
            사장->>사장: 우선 소진
        else 사용 불가
            사장->>시스템: 폐기 처리 기록
        end
        사장->>시스템: 정기 재고 실사 (실물 vs 전산 비교 → 차이 조정)
    end
```

## 8. 직원 출퇴근 / 스케줄

```mermaid
sequenceDiagram
    actor 사장 as 사장 · 매니저
    actor 직원
    participant 시스템

    rect rgb(240, 248, 255)
        Note over 사장, 시스템: 스케줄 작성
        사장->>시스템: 주간 스케줄 작성 (직원별 요일/시간 배정)
        사장->>시스템: 스케줄 확정
        시스템->>직원: 스케줄 알림 발송
    end

    rect rgb(240, 255, 245)
        Note over 사장, 시스템: 출퇴근 (매일 반복)
        직원->>시스템: 출근 체크 (POS/모바일)
        시스템->>시스템: 출근 시간 기록
        직원->>직원: 근무 중
        직원->>시스템: 휴게 시작/종료 기록
        직원->>시스템: 퇴근 체크
        시스템->>시스템: 근무시간 자동 계산
    end

    opt 스케줄 변경 요청
        직원->>사장: 변경 요청
        alt 승인
            사장->>시스템: 스케줄 수정
        else 거절
            사장->>직원: 원래 스케줄 유지 안내
        end
    end

    rect rgb(255, 248, 240)
        Note over 사장, 시스템: 월말 집계
        시스템->>시스템: 직원별 월간 근무시간 집계
        시스템->>시스템: 지각/조퇴/결근 자동 표시
        시스템->>사장: 급여 정산 참고자료 (엑셀/PDF)
    end
```

## 9. 포인트 / 쿠폰 / 마케팅

```mermaid
sequenceDiagram
    actor 사장
    participant 직원
    participant 시스템
    actor 고객

    rect rgb(240, 255, 245)
        Note over 사장, 고객: 포인트
        직원->>시스템: 결제 완료
        alt 회원 고객
            시스템->>시스템: 결제액 × 적립률 = 포인트 적립
            시스템->>고객: 적립 알림
        else 비회원
            시스템-->>고객: 적립 불가 → 가입 유도
        end
        고객->>직원: 포인트 사용 요청
        직원->>시스템: 사용 금액 입력
        시스템->>시스템: 잔액 확인 → 차감
    end

    rect rgb(240, 248, 255)
        Note over 사장, 고객: 쿠폰
        사장->>시스템: 쿠폰 생성 (금액할인/퍼센트/메뉴증정)
        사장->>시스템: 조건 설정 (최소금액/유효기간/대상)
        alt 자동 발급
            시스템->>고객: 가입축하/생일/재방문 쿠폰 발급
        else 수동 발급
            사장->>시스템: 대상 선택 → 발송
            시스템->>고객: 쿠폰 발송
        end
        고객->>직원: 결제 시 쿠폰 제시
        직원->>시스템: 쿠폰 스캔/번호 입력
        시스템->>시스템: 유효성 + 조건 확인 → 할인 적용
    end

    rect rgb(255, 248, 240)
        Note over 사장, 고객: 마케팅 알림
        사장->>시스템: 대상 선택 (전체/단골/미방문/생일자)
        사장->>시스템: 내용 작성 (신메뉴/이벤트/할인)
        시스템->>고객: 푸시/SMS/카카오톡 (수신동의 고객만)
    end
```

## 10. 가게 하루 운영

```mermaid
sequenceDiagram
    actor 사장 as 사장 · 매니저
    participant 시스템

    rect rgb(255, 248, 240)
        Note over 사장, 시스템: 오픈 준비
        사장->>시스템: 출근 → 로그인
        시스템-->>사장: 오늘의 예약 현황
        시스템-->>사장: 오늘의 직원 스케줄
        시스템-->>사장: 재고 부족 알림
        alt 부족 품목 있음
            사장->>시스템: 긴급 발주 or 메뉴 품절 처리
        end
        사장->>사장: 메뉴판 최종 점검 → 영업 시작
    end

    rect rgb(240, 255, 245)
        Note over 사장, 시스템: 영업 중
        loop 영업시간 동안 반복
            사장->>사장: 손님 맞이 → 주문 → 조리 → 서빙 → 결제
        end
        사장->>시스템: 중간 매출 현황 확인
        사장->>시스템: 중간 재고 상태 확인
        사장->>사장: 예약 손님 도착 관리
    end

    rect rgb(240, 248, 255)
        Note over 사장, 시스템: 마감
        사장->>시스템: 오늘 매출 확인 (총매출/수단별/메뉴별)
        사장->>사장: 현금 시재 확인 (전산 vs 실제)
        시스템-->>사장: 일일 마감 리포트
        사장->>시스템: 내일 재고 부족 품목 확인
        alt 발주 필요
            사장->>시스템: 발주서 작성
        end
        사장->>사장: 마감 완료
    end
```

## 11. 메뉴 관리

```mermaid
sequenceDiagram
    actor 사장 as 사장 · 매니저
    participant 시스템
    participant 노출채널 as POS · QR · 고객앱

    rect rgb(240, 248, 255)
        Note over 사장, 노출채널: 새 메뉴 등록
        사장->>시스템: 기본 정보 입력 (이름/가격/설명)
        사장->>시스템: 사진 업로드
        사장->>시스템: 카테고리 분류 + 표시 순서
        opt 옵션 필요 시
            사장->>시스템: 옵션 그룹 설정 (맵기/사이즈/토핑 + 추가금액)
        end
        opt 재고 연동 시
            사장->>시스템: 레시피 등록 (식자재 + 소요량)
        end
        사장->>시스템: 저장
        시스템->>노출채널: 즉시 반영
    end

    rect rgb(255, 248, 240)
        Note over 사장, 노출채널: 영업 중 운영
        alt 품절 발생
            사장->>시스템: 품절 토글 ON
            시스템->>노출채널: 품절 표시 (주문 불가)
        end
        alt 재입고
            사장->>시스템: 품절 토글 OFF
            시스템->>노출채널: 품절 해제
        end
    end

    opt 시간대별 메뉴
        사장->>시스템: 노출 시간대 설정 (예: 런치 11~14시)
        시스템->>노출채널: 해당 시간에만 자동 노출
    end
```

## 12. 테이블 관리

```mermaid
sequenceDiagram
    participant 홀직원
    participant 시스템

    rect rgb(240, 248, 255)
        Note over 홀직원, 시스템: 상태 순환 (반복)
        시스템->>시스템: 상태: 빈자리
        홀직원->>시스템: 손님 안내 → 주문 시작
        시스템->>시스템: 상태: → 이용중
        Note over 홀직원: 주문 → 조리 → 서빙 → 식사
        홀직원->>시스템: 결제 처리
        시스템->>시스템: 상태: → 청소중
        홀직원->>시스템: 테이블 정리 완료
        시스템->>시스템: 상태: → 빈자리 (순환)
    end

    rect rgb(255, 248, 240)
        Note over 홀직원, 시스템: 예약 테이블
        시스템->>시스템: 예약 시간 임박 → 상태: 예약
        alt 손님 도착
            홀직원->>시스템: 예약 확인 → 안내
            시스템->>시스템: 상태: → 이용중
        else 노쇼
            시스템->>시스템: 상태: → 빈자리 (해제)
        end
    end

    rect rgb(240, 255, 245)
        Note over 홀직원, 시스템: 특수 상황
        홀직원->>시스템: 합석 요청 → 테이블 묶기
        시스템->>시스템: 통합 주문으로 관리
        홀직원->>시스템: 더치페이 → 주문 분리
        시스템->>시스템: 각각 결제 처리
        홀직원->>시스템: 테이블 이동
        시스템->>시스템: 주문을 다른 테이블로 이전
    end
```
