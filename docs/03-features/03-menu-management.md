# FR-03. 메뉴 관리

## 목적
가게마다 메뉴 구성 방식이 다르므로, **유연하게(유도리 있게) 커스터마이즈 가능한** 메뉴 관리 시스템. 카테고리·옵션·세트·가용성(품절/시간대)을 자유롭게 구성할 수 있어야 함.

## 핵심 설계 원칙
- 가게별로 사용하는 메뉴 속성이 다름 → **선택적 속성** 구조
- 일부 가게는 옵션이 없고, 일부는 옵션이 매우 복잡함
- 시간대별 메뉴(런치/디너)나 평일/주말 메뉴 구분을 원하는 가게도 있음
- 메뉴 관리자가 사진·설명 등을 자유롭게 편집

## 상세 기능
### 메뉴 기본
- 메뉴 등록/수정/삭제
- 이름, 가격, 설명, 대표 사진(여러 장)
- 카테고리 분류(다단계 가능)
- 표시 순서 조정(드래그)

### 옵션 / 세트
- 옵션 그룹(예: 맵기 / 사이즈 / 토핑)
- 옵션별 추가 금액
- 필수/선택 옵션, 단일/복수 선택
- 세트 메뉴(구성 메뉴 + 할인가)

### 가용성 관리
- 품절 토글(매진 아웃)
- 신메뉴 배지
- 시간대별 노출(런치 한정, 디너 한정)
- 요일별 노출
- 노출 on/off (메뉴판에서 숨김)

### 추가 속성 (선택 사용)
- 원산지, 알레르기 정보
- 조리 시간(예상)
- 칼로리, 영양 정보
- 태그(매운맛, 인기, 추천 등)

### 메뉴 복사/일괄 관리
- 메뉴 복제
- 카테고리별 일괄 가격 인상/할인

## 화면/흐름 스케치
- **메뉴 관리 리스트**: 카테고리 트리 + 메뉴 리스트
- **메뉴 상세 편집**: 기본정보, 옵션 그룹, 가용성, 사진 탭
- **옵션 그룹 라이브러리**: 재사용 가능한 옵션 템플릿

## 데이터 입출력
- 입력: 메뉴 정보 일체
- 출력: POS·QR·KDS·고객앱에 공통 노출되는 메뉴 데이터

## 다른 기능과의 연동
- **주문/POS** (FR-01), **QR 주문** (FR-02): 주문 가능 메뉴 제공
- **재고** (FR-05): 메뉴별 레시피(식자재 구성) 정의 → 마감 시 예상 사용량 참고값으로 활용. 레시피 사용량(+수율)과 최신 입고 단가로 **메뉴별 원가·원가율 자동 표시** (FR-10)
- **주방 KDS** (FR-08): 조리 시간 등 표시
- **통계** (FR-10): 메뉴별 판매 집계
