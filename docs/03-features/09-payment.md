# FR-09. 결제

## 목적
현금·카드·간편결제를 지원하는 결제 처리 기능. 쿠폰·포인트·수동 할인 적용 가능.

## 지원 결제 수단
- **현금**
- **카드** (POS 단말 연동 / VAN사 연동)
- **간편결제**: 카카오페이, 네이버페이, 페이코, 제로페이 등
- (선불 QR 주문) **온라인 결제**: 카드/간편결제

## 상세 기능

### 결제 단말 연동 모드 (가게 설정)
- **연동 모드**: POS ↔ 카드단말(VAN) 직접 연동 — 금액 자동 전달, 승인 결과 자동 기록
- **미연동 모드**: 매장의 기존 카드단말에서 별도 결제 → POS에는 결제 결과만 기록
  - 기존 VAN 계약/단말을 그대로 수용 → 도입 장벽 없음, 모든 매장 즉시 사용 가능
  - 미지원 VAN 매장 및 MVP 단계의 기본 모드
  - 금액 수기 입력 실수 대비: 일일 마감 시 카드 매출 대사 기능으로 보완
- 상세 배경: `../09-research/02-payment-integration.md` 참조

### 결제 처리
- 결제 수단 선택
- 분할 결제(현금 + 카드 등 혼합)
- 더치페이(인원수/금액 분할)
- 결제 영수증 발행(지류/전자)

### 할인/혜택 적용
- 쿠폰 사용
- 포인트 사용
- 수동 할인(금액/퍼센트, 권한 필요)
- 서비스 처리(0원 결제)

### 간편결제 연동
- 고객 바코드/QR 스캔 방식
- 매장 QR 방식
- 결제 완료 콜백 수신

### 환불 처리

#### 환불 조건
- **영수증 필수** — 지류 영수증 또는 전자 영수증 확인 후에만 환불 가능
- **환불 권한**: 매니저 이상 (홀 직원 단독 환불 불가 — 가게 설정으로 변경 가능)
- 주문 취소 규정은 `01-order-pos.md` 참조

#### 환불 수단
- **원래 결제 수단으로 환불**: 카드 → 카드 취소, 현금 → 현금 반환
- **간편결제**: 해당 PG사를 통한 결제 취소
- **선불 QR 결제**: PG사 온라인 결제 취소

#### 부분 환불
- 특정 메뉴 항목만 선택하여 환불 가능
- 분할 결제(현금+카드 등)로 결제한 경우: 환불 대상 금액을 어느 결제 수단에서 차감할지 선택

#### 쿠폰/포인트 환불
- 쿠폰으로 할인받은 부분 환불 시: 쿠폰 복원 (유효기간 남은 경우)
- 포인트로 결제한 부분 환불 시: 포인트로 복원
- 환불로 적립된 포인트: 환불 시 차감

#### 환불 기록
- 환불 사유, 금액, 처리자, 원본 영수증 정보 기록
- 환불 영수증 별도 발행
- 통계에서 환불 금액 별도 집계 (매출 차감 반영)

### 미수금 처리 (무단 이탈)
- 먹튀 등 무단 이탈 시 직원이 해당 테이블을 **미수금** 상태로 처리
- 주문 내역·금액은 보존, 결제 상태만 "미수금"으로 기록
- 미수금 사유 메모 (먹튀, 분쟁, 기타)
- 미수금 내역 별도 관리: 일별/월별 미수금 조회
- 회수 시 미수금 → 결제 완료 전환 가능
- 통계에서 미수금 금액은 실매출과 구분 집계
- QR 세션도 함께 종료 처리 (세션 토큰 무효화)

### 영수증/세무
- 지류 영수증 인쇄
- 전자 영수증 발송(SMS/카카오톡)
- 현금영수증 발급(국세청 연동 — TBD)
- 세금계산서(법인/사업자 대상 — TBD)
