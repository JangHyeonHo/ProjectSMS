# FR-09. 결제

## 목적
현금·카드·간편결제를 지원하는 결제 처리 기능. 쿠폰·포인트·수동 할인 적용 가능.

## 지원 결제 수단
- **현금**
- **카드** (POS 단말 연동 / VAN사 연동)
- **간편결제**: 카카오페이, 네이버페이, 페이코, 제로페이 등
- (선불 QR 주문) **온라인 결제**: 카드/간편결제

## 상세 기능

### 결제 처리
- 결제 수단 선택
- 분할 결제(현금 + 카드 등 혼합)
- 더치페이(인원수/금액 분할)
- 결제 취소/환불
- 결제 영수증 발행(지류/전자)

### 할인/혜택 적용
- 쿠폰 사용
- 포인트 사용
- 수동 할인(금액/퍼센트, 권한 필요)
- 서비스 처리(0원 결제)

### 간편결제 연동
- 고객 바코드/QR 스캔 방식
- 매장 QR 방식
- 결제 완료 콜백 수신

### 미수금 처리 (무단 이탈)
- 먹튀 등 무단 이탈 시 직원이 해당 테이블을 **미수금** 상태로 처리
- 주문 내역·금액은 보존, 결제 상태만 "미수금"으로 기록
- 미수금 사유 메모 (먹튀, 분쟁, 기타)
- 미수금 내역 별도 관리: 일별/월별 미수금 조회
- 회수 시 미수금 → 결제 완료 전환 가능
- 통계에서 미수금 금액은 실매출과 구분 집계
- QR 세션도 함께 종료 처리 (세션 토큰 무효화)

### 영수증/세무
- 지류 영수증 인쇄
- 전자 영수증 발송(SMS/카카오톡)
- 현금영수증 발급(국세청 연동 — TBD)
- 세금계산서(법인/사업자 대상 — TBD)

## 다른 기능과의 연동
- **주문/POS** (FR-01): 결제 완료 시 주문 확정
- **고객앱** (FR-11): 포인트 적립/사용
- **통계** (FR-10): 매출 집계
