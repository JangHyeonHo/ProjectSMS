# FR-12. 배달 / 포장 (후순위)

## 목적
**우선순위 낮음**. 자체 배달 시스템은 만들지 않고, **외부 배달앱 연동** 수준으로 지원.

## 범위

### 외부 배달앱 연동
- 배달의민족
- 쿠팡이츠
- 요기요
- 네이버 주문 등

### 연동 내용 (추후 상세)
- 외부 앱 주문 수신 → POS·KDS에 통합 표시
- 메뉴/가격 동기화
- 매출 통합 집계
- 주문 상태 업데이트

### 포장 주문
- 매장 내 포장 주문 접수 플래그
- 포장 전용 메뉴/옵션(별도 가격)

## 다른 기능과의 연동
- **주문/POS** (FR-01): 외부 주문도 통합 관리
- **메뉴 관리** (FR-03): 외부 앱 메뉴 동기화
- **통계** (FR-10): 채널별(매장/배민/쿠팡) 매출 분석
