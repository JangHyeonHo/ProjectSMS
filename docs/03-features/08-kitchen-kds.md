# FR-08. 주방 KDS / 프린터

## 목적
주방에서 주문을 실시간으로 확인하고, 완료 처리를 할 수 있도록 **KDS(Kitchen Display System)**와 **프린터 출력** 모두를 지원.

## 설계 원칙

KDS는 **주방을 재촉하는 도구가 아니라, 홀에서 현황을 파악하는 도구**입니다.

- 주방은 바쁠 때 버튼을 여러 번 누를 여유가 없음
- 따라서 주방 직원의 터치는 **"완료" 한 번만**
- 경과시간은 참고용으로 표시하되, 주방에 경고/압박하지 않음
- 홀/사장 화면에서 "주문 후 N분 경과" 표시로 밀리는 주문 파악

## 상세 기능

### KDS (주방 화면)
- 주문 카드 실시간 표시 (도착 순서대로 위에서 아래)
- 메뉴, 옵션, 요청사항 표시
- 경과시간 표시 (참고용, 경고 색상 없음)
- **터치는 "완료" 한 번만** — 음식이 나갈 때 터치
- 완료 시 카드 사라짐 + 홀 직원에게 서빙 알림
- 주방 파트별(냉장/화덕/디저트) 화면 분리 가능
- 신규 주문 도착 시 소리/진동 알림

### 홀/사장 화면 (현황 파악용)
- 테이블별 "주문 후 경과시간" 표시
- 오래 걸리는 주문 식별 (홀에서 주방에 확인 가능)
- 주문→완료까지 리드타임 통계 (사장 대시보드)

### 주문 흐름 상태 (2단계로 단순화)
- **대기** → 주문 도착, KDS에 카드 표시
- **완료** → 주방 직원이 "완료" 터치 → 홀에 서빙 알림

### 프린터 출력
- 주문서 자동 인쇄(영수증 프린터 / 주방 티켓 프린터)
- 테이블·주문·메뉴·옵션·요청사항 포함
- 주문 추가/취소 시 재출력
- 영수증 프린터(고객용) 분리 지원

## 화면/흐름 스케치
- **KDS 메인**: 카드 그리드(2~4열), 도착 순서대로 배치
- **카드**: 테이블번호, 메뉴 리스트, 옵션, 경과시간(참고용), 완료 버튼

## 다른 기능과의 연동
- **주문/POS** (FR-01), **QR 주문** (FR-02): 주문 이벤트 수신
- **메뉴 관리** (FR-03): 메뉴 정보 표시
- **통계** (FR-10): 주문→완료 리드타임 분석 (사장 참고용)
