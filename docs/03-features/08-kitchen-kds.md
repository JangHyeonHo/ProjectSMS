# FR-08. 주방 KDS / 프린터

## 목적
주방에서 주문을 실시간으로 확인하고 조리 상태를 관리할 수 있도록 **KDS(Kitchen Display System)**와 **프린터 출력** 모두를 지원.

## 상세 기능

### KDS (화면)
- 주문 카드 실시간 표시(신규 → 조리중 → 완료)
- 주문 접수 후 경과시간 표시(색상으로 긴급도 표시)
- 메뉴 옵션/요청사항 표시
- 터치로 조리중/완료 상태 변경
- 주방 파트별(냉장/화덕/디저트) 화면 분리 가능
- 소리/진동 알림

### 프린터 출력
- 주문서 자동 인쇄(영수증 프린터 / 주방 티켓 프린터)
- 테이블·주문·메뉴·옵션·요청사항 포함
- 주문 추가/취소 시 재출력
- 영수증 프린터(고객용) 분리 지원

### 주문 흐름 상태
- **신규** → 주방 도착
- **조리중** → 시작 버튼
- **완료** → 홀 직원 알림
- **서빙완료** → 자동/수동 표시

## 화면/흐름 스케치
- **KDS 메인**: 카드 그리드(2~4열), 경과시간 색상
- **카드**: 테이블번호, 메뉴 리스트, 옵션, 경과시간, 상태 버튼

## 다른 기능과의 연동
- **주문/POS** (FR-01), **QR 주문** (FR-02): 주문 이벤트 수신
- **메뉴 관리** (FR-03): 조리시간 정보
- **통계** (FR-10): 주문→완료 리드타임 분석
