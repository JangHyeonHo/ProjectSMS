# FR-10. 통계 / 분석 대시보드

## 목적
사장이 운영 현황을 한눈에 파악할 수 있는 **상세 분석 대시보드** 제공. 매출·메뉴·고객·시간대별 등 다각도 분석.

## 상세 기능

### 매출 분석
- 일/주/월/연 단위 매출
- 결제 수단별 매출 비중
- 매출 트렌드 그래프(전년/전월 비교)
- 객단가, 방문 횟수, 테이블 회전율

### 메뉴 분석
- 메뉴별 판매량/매출 순위(베스트/워스트)
- 카테고리별 매출
- 시간대별 인기 메뉴

### 원가·손익 관리 (`../09-research/03-cost-profit.md` 참조)
- **메뉴별 원가율 자동 계산**: 레시피 사용량 × **최신 입고 단가** 기준
  - 입고 단가 변경 시 관련 메뉴 원가율 자동 재계산
  - 원가율 임계치(가게 설정, 예: 40%) 초과 메뉴 경고
  - 목표 원가율 기반 판매가 역산 제안
- **이론 vs 실제 원가율 비교**: 레시피 기준 이론값 vs 기간 실사용액 기준 실제값 → 차이 = 로스(폐기·과다사용) 지표
- **운영비 관리**:
  - 고정비 항목 등록 (월세, 보험, 통신·구독료 등 — 월 단위 반복 입력)
  - 인건비: 직원 근무기록(FR-06) 연동 자동 집계
  - 변동비: 재료비(입고액), 결제 수수료 자동 수집
- **월 손익 리포트**: 매출 − 재료비 − 인건비 − 고정비 = 영업이익
- **손익분기점(BEP)**: 고정비·공헌이익률 기반 월 목표 매출 + 이번 달 진행률 표시

### 시간대/요일 분석
- 시간대별 매출·주문 수
- 요일별 매출 패턴
- 피크 타임 분석

### 고객 분석
- 신규/재방문 고객 비율
- 고객별 방문 빈도/누적 매출
- 단골 고객 리스트

### 테이블 분석
- 테이블별 회전율
- 평균 착석 시간
- 테이블별 매출

### 직원 분석
- 직원별 처리 주문 수(운영 참고용)
- 근무시간 대비 주문 처리량

### 예약 분석
- 예약 전환율
- 노쇼율
- 예약 경로별 분포

### 실시간 대시보드
- 오늘의 매출 진행률
- 현재 테이블 상태
- 실시간 주문 수

### 리포트 출력
- PDF/엑셀 다운로드
- 기간 지정 커스텀 리포트
