# FR-04. 테이블 관리

## 목적
가게의 테이블 배치를 설정하고, 실시간 상태를 관리하며, 테이블별 QR 코드를 생성·관리하는 기능.

## 상세 기능

### 배치도 에디터
- 가게 평면도 상에 테이블을 자유롭게 배치
- 테이블 모양/크기/위치 조정
- 층·구역 구분(1층/2층, 룸/홀 등)
- 테이블 번호/이름 지정
- 최대 수용 인원 설정

### 테이블 상태 관리
- 실시간 상태: **빈자리 / 이용중 / 예약 / 청소중 / 사용불가**
- 주문/결제 연동으로 자동 상태 갱신
- 테이블별 착석 시간·회전 시간 표시

### 합석 / 분리
- 여러 테이블을 하나로 합쳐서 주문 관리
- 한 테이블 주문을 나누어 결제 가능(더치페이)
- 테이블 이동(주문을 다른 테이블로 옮김)

### QR 코드 관리
- 테이블별 고유 QR 자동 생성
- QR 인쇄용 템플릿 제공
- QR 재발급(테이블 변경 시)

## 화면/흐름 스케치
- **배치도 화면**: 메인 대시보드. 각 테이블 상태가 색상·아이콘으로 표시
- **배치도 에디터**: 드래그&드롭으로 테이블 배치
- **테이블 상세**: 현재 주문, 착석 시간, 메모, 합석/이동 버튼

## 데이터 입출력
- 입력: 테이블 배치 정보, 상태 변경 이벤트
- 출력: 실시간 테이블 상태, QR 토큰

## 다른 기능과의 연동
- **주문/POS** (FR-01): 테이블 선택, 주문 연결
- **QR 주문** (FR-02): 테이블별 QR 토큰 발급
- **예약** (FR-07): 예약된 테이블 표시
- **통계** (FR-10): 테이블 회전율 분석
