# FR-06. 직원 / 인사 관리

## 목적
기본 인사 정보 + 스케줄 + 근무시간 + 권한 관리. **성과 관리는 제외**.

## 상세 기능

### 기본 인사 관리
- 직원 등록(이름, 연락처, 생년월일, 입사일)
- 직급/역할 지정
- 고용 형태(정규/알바/파트타임)
- 시급/월급 등 급여 기준(계산은 단순 집계 수준)
- 퇴사 처리

### 권한 관리
- 역할별 권한 설정(`02-user-roles.md` 참조)
- 직원별 커스텀 권한 부여
- 로그인 계정 생성/초대

### 스케줄 관리
- 주간/월간 스케줄 캘린더
- 직원별 근무 요일/시간 배정
- 교대 근무 패턴(템플릿)
- 스케줄 변경 요청/승인

### 근무시간 관리 (출퇴근)
- 출근/퇴근 기록(POS 단말 또는 모바일에서)
- 체크인 방식: 비밀번호 / QR / 위치 확인 (TBD)
- 휴게시간 기록
- 근무시간 자동 집계
- 지각/조퇴/결근 표시
- 월별 근무시간 리포트(급여 정산용)

### 예외 상황 처리

실제 현장에서 자주 발생하는 상황들을 시스템이 지원해야 합니다.

#### 결근 / 못 나오는 경우
- **사전 결근 신고**: 직원이 앱/전화로 결근 사유 등록 (병가, 개인사정 등)
- **당일 갑작스러운 결근**: 사장/매니저가 확인 후 결근 처리 + 사유 기록
- **무단결근**: 연락 없이 안 나온 경우, 스케줄 시간 경과 후 자동 "미출근" 표시 → 사장에게 알림

#### 대타 / 교대
- **직원 간 대타 요청**: 직원 A가 "이 날 못 나감" → 대타 가능한 직원 목록 표시 → 직원 B가 수락
- **사장이 직접 대타 배정**: 결근자 발생 시 사장이 다른 직원에게 스케줄 재배정
- **긴급 호출**: 비번인 직원에게 출근 요청 알림 → 수락/거절

#### 지각 / 조퇴
- **지각**: 스케줄 시작 시간 이후 출근 체크 → 자동 지각 표시 + 지각 시간 기록
- **조퇴**: 스케줄 종료 전 퇴근 체크 → 사유 입력 → 사장/매니저 확인
- **중간 외출**: 외출 시작/종료 기록 (개인 사유, 업무 외출 구분)

#### 연장 근무
- **스케줄 초과 근무**: 퇴근 시간 지나서도 계속 근무 → 퇴근 체크 시 연장 시간 자동 계산
- **사장 요청 연장**: 바쁜 날 퇴근 예정 직원에게 연장 요청 → 수락 시 스케줄 자동 연장

#### 비번 출근
- **스케줄 미배정 출근**: 비번인데 나온 경우 → 사장/매니저 승인 후 근무 기록 가능

## 화면/흐름 스케치
- **직원 리스트**: 직원 카드 + 연락처 + 상태
- **스케줄 캘린더**: 주간 뷰, 드래그로 배정
- **출퇴근 기록**: 일별/월별 근무시간 표

## 다른 기능과의 연동
- **주문/POS**: 근무 중인 직원이 주문 처리 → 담당자 기록
- **통계** (FR-10): 직원별 처리 건수(성과 아닌 운영 참고용)
