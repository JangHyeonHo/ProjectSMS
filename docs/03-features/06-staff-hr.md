# FR-06. 직원 / 인사 관리

## 목적
기본 인사 정보 + 스케줄 + 근무시간 + 권한 관리. **성과 관리는 제외**.

## 상세 기능

### 기본 인사 관리
- 직원 등록(이름, 연락처, 생년월일, 입사일)
- 직급/역할 지정
- 고용 형태(정규/알바/파트타임)
- 시급/월급 등 급여 기준(계산은 단순 집계 수준)
- 퇴사 처리

### 권한 관리
- 역할별 권한 설정(`02-user-roles.md` 참조)
- 직원별 커스텀 권한 부여
- 로그인 계정 생성/초대

### 스케줄 관리
- 주간/월간 스케줄 캘린더
- 직원별 근무 요일/시간 배정
- 교대 근무 패턴(템플릿)
- 스케줄 변경 요청/승인

### 근무시간 관리 (출퇴근)
- 출근/퇴근 기록(POS 단말 또는 모바일에서)
- 체크인 방식: 비밀번호 / QR / 위치 확인 (TBD)
- 휴게시간 기록
- 근무시간 자동 집계
- 지각/조퇴/결근 표시
- 월별 근무시간 리포트(급여 정산용)

## 화면/흐름 스케치
- **직원 리스트**: 직원 카드 + 연락처 + 상태
- **스케줄 캘린더**: 주간 뷰, 드래그로 배정
- **출퇴근 기록**: 일별/월별 근무시간 표

## 다른 기능과의 연동
- **주문/POS**: 근무 중인 직원이 주문 처리 → 담당자 기록
- **통계** (FR-10): 직원별 처리 건수(성과 아닌 운영 참고용)
