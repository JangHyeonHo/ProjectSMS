# FR-01. 주문 / POS

## 목적
직원이 테이블 주문을 받고, 주문을 수정/추가/취소하며, 결제 처리 후 영수증을 발행하는 가게 운영의 핵심 기능.

## 사용자 시나리오
1. 손님이 테이블에 앉는다 → 홀 직원이 POS에서 해당 테이블 선택
2. 메뉴 선택(옵션 포함) → 주문 추가
3. 주문이 주방으로 전송(KDS/프린터)
4. 손님이 추가 주문 → 기존 주문에 추가
5. 식사 완료 후 결제 → 영수증 발행 → 테이블 정리

## 상세 기능
- 테이블별 주문 생성/조회/수정/취소
- 메뉴 카테고리/검색으로 빠른 선택
- 옵션 선택(맵기, 토핑, 사이즈 등)
- 주문 메모(요청사항)
- 주문 전송 → 주방 KDS/프린터로 즉시 전달
- 주문 단위 취소/수량 수정(아래 취소 규정 참조)
- 주문 합치기 / 나누기 (더치페이)
- 할인 적용(쿠폰, 포인트, 수동 할인)
- 결제 처리(현금/카드/간편결제 — `09-payment.md` 참조)
- 영수증 발행(지류/전자)
- 객단가, 테이블 회전율 자동 집계

## 주문 취소 규정

**원칙**: 모든 취소는 **직원(POS)만 가능** — 고객(QR 주문 화면)에서는 취소할 수 없음

### 조리 전 취소
- KDS에 도착했지만 아직 조리 시작 전
- 홀 직원이 POS에서 취소 처리
- KDS에서 해당 주문 카드 제거 + 주방에 취소 알림
- 자동 차감된 개수 품목(병/캔)은 **재고 자동 복원**

### 조리 중 취소
- 조리가 시작된 이후 → **매니저 이상 권한** 필요
- 취소 사유 필수 입력
- 식자재 이미 사용 → 재고 복원 없음 (폐기 처리)

### 서빙 후 취소
- **음식 문제** (이물질, 조리 실수, 잘못된 메뉴 서빙): 취소 처리 + 재조리 또는 취소만
- **미개봉 음료** (병/캔 등): 취소 가능 → 재고 복원
- **개봉/소비된 음료 및 음식**: 취소 불가 (고객 변심 포함)
- 서빙 후 취소는 **매니저 이상 권한** 필요
- 취소 사유 + 처리 방식(폐기/재조리/재고복원) 기록

### 취소와 재고 연동
- 자동 차감 품목(병/캔): 취소 시 재고 자동 복원 (미개봉 확인 시)
- 일반 식자재: 마감 차감이므로 취소 시 재고 변동 없음

## 화면/흐름 스케치
- **메인 화면**: 테이블 배치도 + 각 테이블 상태 표시
- **주문 화면**: 좌측 메뉴 카테고리/검색, 우측 현재 주문 리스트
- **결제 화면**: 결제수단 선택, 할인 적용, 총액 확인

## 데이터 입출력
- 입력: 테이블 ID, 메뉴 ID, 옵션, 수량, 메모
- 출력: 주문(Order) 레코드, 주방 전송 이벤트, 결제 완료 시 매출 집계 반영

## 다른 기능과의 연동
- **메뉴 관리** (FR-03): 메뉴·옵션 구성 참조
- **테이블 관리** (FR-04): 테이블 상태 갱신
- **재고** (FR-05): 개수 품목(병/캔)은 주문 시 자동 차감, 일반 식자재는 마감 시 수동 차감
- **주방 KDS** (FR-08): 주문 이벤트 전송
- **결제** (FR-09): 결제 완료 처리
- **통계** (FR-10): 매출 집계
