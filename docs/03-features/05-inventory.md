# FR-05. 재고 / 식자재 관리

## 목적
식자재의 입출고, 자동 차감(레시피 기반), 발주, 유통기한, 거래처를 체계적으로 관리하는 **상세 재고관리** 기능.

## 상세 기능

### 식자재 등록
- 식자재명, 단위(kg/g/개/L/ml), 기본 단가
- 카테고리(야채/육류/수산/소스/포장재 등)
- 거래처 연결
- 바코드/이미지(선택)

### 입출고 관리
- 입고 등록(거래처, 수량, 단가, 입고일)
- 출고 기록(사용/폐기)
- 실시간 재고 수량 집계

### 자동 차감 (레시피 연동)
- 메뉴별 레시피 등록(식자재 + 필요량)
- 주문 접수/완료 시 해당 식자재 자동 차감
- 수동 조정(차이 보정)

### 발주 관리
- 최소 재고 기준 설정 → 부족 시 알림
- 발주서 작성 및 거래처 전송(메일/출력)
- 발주 이력/상태 관리

### 유통기한
- 로트(LOT)별 유통기한 입력
- 임박 알림(설정 가능한 기간)
- 폐기 처리 기록

### 거래처 관리
- 거래처 정보(연락처, 담당자, 거래 조건)
- 거래처별 발주 이력
- 거래처별 단가 관리

### 재고 실사
- 실사 날짜 등록
- 전산 재고 vs 실제 재고 비교
- 차이 조정

### 리포트
- 식자재 사용량 분석
- 원가율 분석(메뉴당 원가)
- 재고 회전율

## 다른 기능과의 연동
- **메뉴 관리** (FR-03): 레시피(메뉴-식자재 매핑)
- **주문/POS** (FR-01): 주문 확정 시 자동 차감
- **통계** (FR-10): 원가·재고 분석
