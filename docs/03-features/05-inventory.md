# FR-05. 재고 / 식자재 관리

## 목적
식자재의 입출고, 차감, 발주, 유통기한, 거래처를 체계적으로 관리하는 **상세 재고관리** 기능.

## 차감 방식 — 현실 반영

음식점 특성상, 모든 식자재를 레시피 기반으로 정밀하게 자동 차감하는 것은 **비현실적**입니다.
조리 과정에서 재료 사용량이 매번 달라지기 때문입니다. 따라서 **2가지 차감 방식을 병행**합니다:

| 구분 | 대상 | 방식 | 예시 |
|------|------|------|------|
| **즉시 자동 차감** | 개수 단위로 1:1 대응 가능한 품목 | 주문 시 자동 차감 | 병맥주, 캔음료, 포장 음료 등 |
| **일일 마감 차감** | 조리에 사용되는 일반 식자재 | 마감 시 실제 사용량 확인 후 수동 차감 | 야채, 육류, 소스, 생맥주 등 |

식자재 등록 시 **차감 유형(자동/수동)**을 지정할 수 있어야 합니다.

## 상세 기능

### 식자재 등록
- 식자재명, 단위(kg/g/개/L/ml), 기본 단가
- 카테고리(야채/육류/수산/소스/포장재 등)
- 거래처 연결
- 바코드/이미지(선택)

### 입출고 관리
- 입고 등록(거래처, 수량, 단가, 입고일)
- 출고 기록(사용/폐기)
- 실시간 재고 수량 집계

### 즉시 자동 차감 (개수 단위 품목)
- 병/캔 등 개수 단위로 1:1 매핑되는 품목만 해당
- 주문 접수 시 해당 품목 자동 차감
- 예: 병맥주 1병 주문 → 재고에서 1개 차감

### 일일 마감 차감 (일반 식자재)
- 조리에 사용되는 대부분의 식자재
- 마감 시 실제 사용량을 직원이 확인·입력하여 차감
- 레시피 기반 예상 사용량을 참고값으로 표시 (강제 아님)
- 수동 조정(차이 보정)

### 발주 관리
- 최소 재고 기준 설정 → 부족 시 알림
- 발주서 작성 및 거래처 전송(메일/출력)
- 발주 이력/상태 관리

### 유통기한
- 로트(LOT)별 유통기한 입력
- 임박 알림(설정 가능한 기간)
- 폐기 처리 기록

### 거래처 관리
- 거래처 정보(연락처, 담당자, 거래 조건)
- 거래처별 발주 이력
- 거래처별 단가 관리

### 재고 실사
- 실사 날짜 등록
- 전산 재고 vs 실제 재고 비교
- 차이 조정

### 리포트
- 식자재 사용량 분석
- 원가율 분석(메뉴당 원가)
- 재고 회전율

## 다른 기능과의 연동
- **메뉴 관리** (FR-03): 레시피(메뉴-식자재 매핑)
- **주문/POS** (FR-01): 개수 단위 품목은 주문 시 자동 차감, 일반 식자재는 마감 시 수동 차감
- **통계** (FR-10): 원가·재고 분석
