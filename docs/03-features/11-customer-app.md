# FR-11. 고객앱 (포인트 / 쿠폰 / 마케팅 알림)

## 목적
단골 고객을 위한 포인트·쿠폰·마케팅 알림 기능. 재방문 유도와 관계 유지.

## 상세 기능

### 포인트
- 결제 금액 기준 자동 적립(비율 설정)
- 사용(결제 시 차감)
- 포인트 유효기간 관리
- 포인트 이력 조회
- 생일/이벤트 보너스 포인트

### 쿠폰
- 쿠폰 발행(금액 할인, 퍼센트, 증정 메뉴)
- 쿠폰 조건(최소 주문 금액, 특정 메뉴, 시간대)
- 쿠폰 유효기간
- 사용 이력
- 발행 경로: 가입 축하, 생일, 재방문 유도, 이벤트

### 마케팅 알림
- 푸시 알림, SMS, 카카오톡 알림톡
- 대상 필터: 전체 / 단골 / 미방문 고객 / 생일자
- 신메뉴 소식, 이벤트, 할인 안내
- 수신 동의/거부 관리(법적 준수)

### 고객 프로필 (가게 시점)
- 방문 횟수, 최근 방문일
- 누적 결제액
- 선호 메뉴
- 메모(알레르기, 취향)

### 고객앱 기능 (고객 시점)
- 내 포인트/쿠폰 확인
- 방문 이력
- 즐겨찾기 가게(멀티테넌트 상 여러 가게 통합)
- 알림 수신

## 다른 기능과의 연동
- **결제** (FR-09): 포인트 적립/사용
- **예약** (FR-07): 예약 알림 통합
- **통계** (FR-10): 고객 분석
- **고객 로그인** (`02-user-roles.md`)
