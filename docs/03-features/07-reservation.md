# FR-07. 예약 관리

## 목적
**전방위 예약** — 직원 수동 등록, 고객 온라인 예약, 네이버/카카오 예약 플랫폼 연동을 통합 관리.

## 예약 경로 (Channels)
1. **직원 수동 등록**: 전화·방문 예약을 직원이 입력
2. **고객 온라인 예약**: 고객앱/가게 웹페이지에서 직접 예약
3. **외부 플랫폼 연동**: 네이버 예약, 카카오 예약, 캐치테이블 등

## 상세 기능

### 예약 등록
- 예약자 정보(이름, 연락처, 인원수)
- 예약 일시, 테이블 배정
- 메모(요청사항, 알레르기, 단골 표시)
- 예약 상태: **대기/확정/방문완료/노쇼/취소**

### 예약 캘린더
- 일/주 뷰
- 시간대별 예약 현황
- 테이블별 예약 가시화

### 자동 알림
- 예약 확정 알림(SMS/카카오톡)
- 방문 전일/당일 리마인드
- 예약 취소/변경 알림

### 노쇼 관리
- 노쇼 기록
- 반복 노쇼 고객 식별
- 예약금/보증금 정책(선택)

### 외부 플랫폼 연동
- 네이버 예약 API 연동(예약 동기화)
- 카카오 예약 연동(TBD)
- 외부 예약도 내부 캘린더에 통합

## 화면/흐름 스케치
- **예약 캘린더**: 일/주 뷰, 색상으로 상태 표시
- **예약 등록**: 날짜·시간·인원 → 가능 테이블 자동 제안
- **고객 예약 페이지**: 날짜 선택 → 시간 선택 → 정보 입력

## 다른 기능과의 연동
- **테이블 관리** (FR-04): 예약된 테이블 상태 반영
- **고객앱** (FR-11): 고객 예약 이력, 알림
- **통계** (FR-10): 예약 전환율, 노쇼율
