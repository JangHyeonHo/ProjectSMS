# 리서치 01. 하드웨어 (POS 단말 · 프린터 · KDS · 테이블 단말)

> 조사 시점: 2026-07. 가격/정책은 변동 가능, 계약 전 재확인 필요.

## 1. POS 단말

### 시장 현황

국내 POS 시장은 크게 3가지 흐름으로 나뉩니다.

| 유형 | 대표 업체/제품 | 특징 |
|------|---------------|------|
| **전용 POS 일체형** | 포스뱅크(APEXA 시리즈), OKPOS | 전통 강자. Windows/Android 일체형 단말 + 지역 대리점 유통망. 안정적이지만 폐쇄적 |
| **태블릿 기반 클라우드 POS** | 페이히어, 토스포스, 그로잉세일즈 | 범용 태블릿/스마트폰/PC에 앱 설치. 월 구독형(0~15만원 수준). 최근 소상공인 시장 주류 |
| **결제단말 일체형 생태계** | 토스플레이스(토스프론트) | 결제단말+POS 수직 통합. 토스프론트 단말가 26만원(2026-03 기준). 외부 POS 연동 가이드 공개(docs.tossplace.com) |

참고: [Shopify 2026 POS 비교](https://www.shopify.com/kr/blog/pos-systems-small-business), [토스플레이스 하드웨어](https://tossplace.com/story/tossplace_hardware), [페이히어](https://payhere.in/)

### 우리 시스템 관점 시사점

- 우리는 SaaS이므로 **자체 하드웨어 제조는 하지 않고, 범용 태블릿(Android) + 웹/앱 POS**가 자연스러운 방향 (페이히어 모델과 동일)
- 이 경우 핵심 과제는 하드웨어 자체가 아니라 **주변기기 연동**:
  - 영수증/주방 프린터 제어
  - 카드 결제 단말(VAN 단말) 연동 — `02-payment-integration.md` 참조
- **웹 POS의 한계**: 브라우저에서는 로컬 프린터/단말 직접 제어가 어려움 → Android 네이티브(또는 하이브리드) 앱으로 프린터·단말과 직접 통신하는 구조가 사실상 필수
- 토스플레이스가 외부 연동 가이드를 공개하고 있어, **토스프론트 단말을 결제 수단으로 연동**하는 옵션도 검토 가능 (자체 VAN 연동 전 과도기 전략으로 유용)

### 미결정 → 선택지 정리

| 선택지 | 장점 | 단점 |
|--------|------|------|
| A. 범용 Android 태블릿 + 자체 POS 앱 | 저비용, SaaS 모델 부합, 하드웨어 종속 없음 | 주변기기 연동 직접 개발 |
| B. 전용 POS 단말(포스뱅크 등)에 설치 | 기존 매장 하드웨어 재활용 가능 | Windows 대응 필요, 기종 파편화 |
| C. 토스플레이스 등 생태계 연동 | 결제 연동 부담 감소 | 플랫폼 종속, 수수료 구조 종속 |

**권장**: A를 기본으로 하되, 결제단말 연동은 C(토스프론트 연동)를 1차 검토 → 장기적으로 VAN 직접 연동.

## 2. 영수증 / 주방 프린터

### 시장 표준

- **감열식(써멀) 80mm** 프린터가 영수증/주방 주문서 표준
- 제어 프로토콜은 **ESC/POS**가 사실상 업계 표준 (엡손이 만든 표준, 국내외 대부분 호환)
- 주요 제조사: **빅솔론(BIXOLON)**, **세우테크(Sewoo)**, **엡손(Epson)**, 포스뱅크

| 제품 예시 | 특징 | 가격대 (조사 시점, 신품) |
|-----------|------|--------------------------|
| 빅솔론 SRP-330II | 보급형 영수증 프린터 | 약 12만원대 |
| 세우테크 SLK-TS400 | 보급형, 배달용으로도 널리 사용 | 약 13만원대 |
| 빅솔론 SRP-350III / 350plusV | 국내 보급률 최상위, 250~400mm/s | 약 17만~32만원 (인터페이스 구성에 따라) |
| 엡손 TM-T88V / T88VII | 글로벌 표준, ESC/POS 원조 | 약 32만~34만원 |
| 빅솔론 SRP-F310II | 350mm/s, **방수·방진(IP12) — 주방 환경용** | 30만원대 추정 (판매처 견적 필요) |

- 가격은 인터넷 판매가 기준 참고치 — **USB 단독 vs LAN/복합 인터페이스 구성에 따라 같은 모델도 가격 차이가 큼** (LAN 모델이 더 비쌈)
- VAT·설치비 별도, 중고 시장도 활성화되어 있음 (신품의 50~70% 수준)

참고: [빅솔론 POS 프린터](https://kr.bixolon.com/product.php?key=pos), [Epson Korea POS 프린터](https://www.epson.co.kr), [다나와 POS프린터](https://search.danawa.com/dsearch.php?query=POS%ED%94%84%EB%A6%B0%ED%84%B0), [나비엠알오 SRP-350III](https://www.navimro.com/p/K17429513/)

### 통신 방식 권장

| 용도 | 권장 | 이유 |
|------|------|------|
| 주방 프린터 | **LAN(이더넷)** | 거리 제약 없음, 블루투스보다 안정적, 여러 단말에서 공유 가능 |
| 카운터 영수증 | LAN 또는 USB | POS 단말 옆이므로 USB도 무방하나, LAN이면 단말 교체에 자유로움 |
| 블루투스 | 비권장(보조용) | 페어링 끊김 이슈, 다중 단말 공유 불가 |

### 개발 관점

- LAN 프린터는 TCP 소켓(보통 9100 포트)으로 ESC/POS 바이너리를 직접 전송하는 방식이 일반적 → Android 앱에서 직접 구현 가능
- 주방/영수증 프린터 분리는 **같은 프로토콜, 다른 IP**로 처리 (가게 설정에서 프린터별 역할 지정)
- 주문 채널별 라우팅(주방 티켓 → 주방 프린터, 영수증 → 카운터)은 소프트웨어 설정 문제

## 3. KDS 단말

### 시장 현황

- 국내외 KDS는 **일반 태블릿(Android/iPad) 거치형**이 주류 — Loyverse KDS, 토스포스 현황(KDS), 그로잉세일즈, OKPOS, 아임유 UP KDS 등 모두 태블릿 앱 형태
- 전용 대형 디스플레이(15~21인치 상업용 Android 패널) 제품도 있으나(메타포스 등) 시장 규모는 작음
- 토스포스는 후불형 매장에도 KDS 기능 제공 시작 — 국내 후불 매장에서도 KDS가 보편화되는 추세

참고: [Loyverse KDS](https://loyverse.com/kitchen-display-system), [토스 KDS](https://tossplace.com/story/postpaid_kds), [메타포스 KDS](https://www.metainno.co.kr/product/kds/)

### 우리 시스템 관점

- **일반 Android 태블릿 + 자체 KDS 웹/앱**으로 충분 (POS와 같은 앱 기반 통일 가능)
- 주방 환경 고려사항: 방수 거치대/케이스, 화면 밝기, 터치 반응(물 묻은 손) — 하드웨어가 아닌 **거치·운영 가이드** 수준으로 해결
- 우리 설계(터치는 "완료" 한 번만)는 저가 태블릿으로도 무리 없음
- 프린터 겸용 운영(KDS + 주방 프린터 병행)이 현장 표준이므로 둘 다 지원 유지

## 4. 테이블 단말 (QR 방식 A 관련)

### 시장 현황 — 테이블오더 단말기

국내 테이블오더 시장은 급성장 중이며, 태블릿 거치형이 표준입니다.

| 업체 | 요금(조사 기준) | 비고 |
|------|----------------|------|
| **티오더** | 3년 약정 시 월 1.8만원/대 (선결제형 +2천원) | 시장 점유율 약 60%로 1위 |
| **하이오더(KT)** | 서비스 1.43만~2.2만원 + 단말 7,700~14,850원/월 | KT 유통망 |
| **페이히어 오더** | 월 1만원대 | POS와 통합 |
| **메뉴잇** | (구체 요금 미확인) | 티오더와 경쟁 구도 |

3사 모두 월 이용료 외 별도 결제 수수료는 없음.

참고: [ZDNet 테이블오더 수수료·요금제](https://zdnet.co.kr/view/?no=20241206173523), [KT 하이오더](https://product.kt.com/wDic/soho/marketing.do?ItemCode=highorder), [이로운넷 — 메뉴잇 vs 티오더](https://www.eroun.net/news/articleView.html?idxno=47021)

### e-ink(전자잉크) QR 표시기 검토

- 전자가격표시기(ESL)는 e-ink 기반으로 **QR코드 동적 표시 가능**, 무선 갱신, 배터리 수년 지속 — 기술적으로는 우리 "방식 A(디지털 QR)"에 부합
- 다만 ESL 생태계는 **소매점 가격표 용도**로 설계됨(중앙 서버·전용 게이트웨이 필요, 갱신 주기 수 초~수십 초). 테이블 회전마다 QR 갱신하는 용도의 기성 솔루션은 없어 커스텀 개발 필요
- 참고: [E Ink ESL](https://kr.eink.com/application/detail/ESL), [전자신문 ESL](https://www.etnews.com/20221108000061)

### 방식 A 재정의 제안

조사 결과, "디지털 QR 표시"의 현실적 선택지는 3가지로 정리됩니다:

| 옵션 | 설명 | 비용 감각 | 평가 |
|------|------|-----------|------|
| **A-1. 태블릿 테이블오더** | 태블릿에서 직접 주문 + (원하면 QR도 표시) | 단말+거치대, 시장가 월 1~2만원/대 수준의 원가 구조 | 시장 표준. QR 없이도 테이블에서 직접 주문 가능해 UX 최상 |
| **A-2. e-ink QR 표시기** | 저전력 소형 디스플레이에 세션 QR만 표시 | 단말 저렴, 게이트웨이/개발 필요 | 기성품 없음, 커스텀 개발 리스크 |
| **B. 세션 QR 영수증 출력** | 착석 시 QR 영수증 전달 | 프린터 재활용, 추가 장비 0 | 초기 도입 장벽 최소 |

### 결정 (2026-07-15)

**태블릿 테이블오더(A-1)는 채택하지 않음.** 사유:
- 티오더 등이 선점한 시장 표준에 합류하면 하드웨어 보급·약정 영업 경쟁이 되어 차별화가 어려움
- 오히려 **"테이블 장비 0원, 고객 폰 QR 중심"**을 제품 정체성으로 삼아 경쟁력 확보
- 세션 보안을 외부 하드웨어/생태계에 맡기지 않고 자체 스택에서 관리
- **기본 방식: B(세션 QR 영수증 출력)** — 추가 장비 없이 도입 가능
- e-ink QR 표시기(A-2)는 인쇄가 부담스러운 매장용 후순위 옵션으로 보류
- 먹튀 대응: 주문자 식별 옵션(기술 로그 / 전화번호 인증 / 선불)으로 보완 — `../03-features/02-qr-ordering.md` 참조

| 테이블 QR (방식 B: 영수증 출력) | — | **기존/카운터 프린터 재활용 = 0원** | 0원 |
| **합계** | | | **약 80만~180만원 (1회성)** |

### 비교: 태블릿 테이블오더 대비

- 티오더 기준 10테이블 매장: 월 18만원(1.8만×10대) × 3년 약정 = **648만원**
- 우리 방식(QR 영수증): 테이블 장비 **0원** — 위 초기 구축비 전체를 합쳐도 테이블오더 1년치 미만
- 기존 매장 전환 시에는 프린터·태블릿 재활용으로 초기 비용이 더 줄어듦 (온보딩 2-트랙: `02-payment-integration.md`)

## 7. 종합 권장안

1. **POS/KDS**: 범용 Android 태블릿 + 자체 앱 (웹 기반 + 네이티브 래퍼로 프린터 제어)
2. **프린터**: ESC/POS 감열식 80mm, 주방은 LAN 필수, 빅솔론/세우테크/엡손 호환 확보
3. **테이블 단말**: 태블릿 테이블오더 미채택(결정) — QR 메인 전략, 방식 B(QR 영수증 출력)가 기본, e-ink는 후순위 옵션
4. **카드 결제 단말**: `02-payment-integration.md`의 VAN/토스플레이스 연동과 함께 결정
5. **바코드 스캐너**: Phase 3으로 연기
