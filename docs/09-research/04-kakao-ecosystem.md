# 리서치 04. 카카오 생태계 연동 (LINE 미니앱 대응)

> 조사 시점: 2026-07. 배경: 일본은 LINE 미니앱으로 매장 메뉴 표시·주문·멤버십을 메신저 안에서 처리하는 방식이 보편화. 한국에서 카카오톡으로 같은 그림이 가능한지 조사.

## 1. 결론 요약

- 카카오에는 **LINE 미니앱과 동일한 "미니앱 플랫폼"이 없음** (메신저 내 서드파티 웹앱 실행 + 프로필/결제 통합을 하나로 묶은 상품 부재)
- 대신 **개별 요소를 조합**하면 유사한 경험 구성 가능: 채널(챗봇) + 카카오싱크(간편가입) + 알림톡/친구톡 + 카카오페이
- 우리 QR 주문 웹은 일반 모바일 웹이므로 **카카오톡 인앱 브라우저에서 그대로 열림** — "앱 설치 없이 메신저에서 바로"라는 LINE 미니앱의 핵심 가치는 QR 웹 방식으로 이미 달성됨

## 3. 우리 아키텍처와의 관계

### 테이블 QR 주문과 카카오 채널의 역할 구분

- **테이블 주문(핵심)**: 세션 QR 스캔 → 모바일 웹. 카카오를 거칠 필요 없음 (세션 = 착석 증명이므로, 채널 링크로는 테이블 세션에 진입 불가)
- **카카오 채널(보조 접점)**: 매장 밖 시나리오에 적합 — 예약, 메뉴 미리보기, 쿠폰 수령, 재방문 유도
- 즉 LINE 미니앱이 하는 일 중 "테이블에서 주문"은 우리 QR 웹이, "매장 밖 고객 관계"는 카카오 채널이 맡는 구도

### 고객앱 단계에서의 활용 (회원 체계 도입 시)

고객 로그인 미도입 결정(2026-07-15)과 연결 — 회원 체계를 도입하는 시점에:
- **카카오싱크로 가입 마찰 최소화** (원클릭 가입, 전화번호·프로필 일괄 수집)
- 가입과 동시에 가게 채널 친구 추가 유도 → 친구톡 마케팅 기반 확보
- 별도 고객앱 설치 없이 "카카오 로그인 + 모바일 웹"으로 포인트/쿠폰 제공 가능 → **네이티브 고객앱 개발을 미루거나 생략하는 옵션**이 됨

## 4. 도입 조건·제약 (중요)

- 카카오싱크: **비즈니스 채널 심사** 필요, 유효한 국내 사업자번호 필수, 카카오 로그인 구현 전제
- **제한 업종 주의**: 주류 관련 업종 등은 수집 정보가 프로필·이메일로 제한되고 간편가입 동의 화면에 채널 노출 불가 → **주점·호프 등 우리 대상 고객 일부가 해당**될 수 있어 확인 필요
- 채널/알림톡은 가게별로 개설·심사 → 멀티테넌트 SaaS로서 **가게별 채널 온보딩 절차**를 우리가 안내/대행하는 구조 설계 필요
- 알림톡 발송 비용 부담 주체는 기존 TBD 유지

## 5. 카카오 간편 인증 = 먹튀 억제 수단 (메뉴 표시 없이 "연계만" 하는 활용)

풀 미니앱/메뉴 연동 없이도, **카카오 로그인(간편 인증)만 연계**하면 QR 주문자 식별에 즉시 활용 가능:

- QR 주문 직전 "카카오로 인증" 원탭 → 카카오 계정 프로필 + (동의 시) 전화번호 확보
- 카카오 계정은 전화번호 기반이므로 **SMS 인증과 동등한 식별력**, 입력 마찰은 더 낮음 (번호 입력·인증번호 대기 불필요)
- 구현 단위가 **플랫폼(우리 서비스) 레벨** — 카카오 로그인 앱 1개로 전체 가게 커버, 가게별 채널 심사 불필요
- 자체 회원 체계(비밀번호, 계정 관리)를 만들지 않고도 식별 가능 → "고객 로그인 미도입" 방침과 양립
- 카카오 미사용 고객은 SMS 인증 폴백
- 한계는 동일: 억제·연락 수단이지 회수 보장 아님. 전화번호 등 추가 항목 수집은 검수·동의 필요

→ `03-features/02-qr-ordering.md` 주문자 식별 수준에 반영됨.
