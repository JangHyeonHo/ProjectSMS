# 리서치 03. 원가율 계산 & 손익 관리

> 조사 시점: 2026-07. 국내 외식업 원가 관리 자료 기반.
> 관련 기능: 재고(FR-05) · 메뉴(FR-03) · 통계(FR-10)

## 1. 원가율 기본 공식

```
원가율(%) = 메뉴 원가 ÷ 판매가 × 100
마진율(%) = 100 − 원가율
판매가 책정(역산) = 원가 ÷ 목표 원가율
```

예: 원가 3,500원, 판매가 10,000원 → 원가율 35%, 마진율 65%
예: 원가 3,500원, 목표 원가율 35% → 판매가 = 3,500 ÷ 0.35 = 10,000원

### 업종별 적정 원가율 (국내 통용 기준)

| 업종 | 적정 원가율 |
|------|-------------|
| 일반 음식점 (한식·중식·분식 등) | 30~40% (통상 목표 30~35%) |
| 패스트푸드 | 25~35% |
| 카페·디저트 | 20~30% |
| 고급 레스토랑 | 40~50% |
| 배달 전문점 | 30~35% (+ 포장재·배달 수수료 별도 반영 필요) |

- 외식업 생존 마지노선: 식재료 원가율 35%, **40% 초과 시 위험 신호**로 통용
- 배달 채널은 식재료 외에 포장재·배달앱 수수료·광고비까지 원가에 넣어야 실제 마진이 보임

## 2. 레시피 원가 계산 방법

메뉴 원가 = Σ (재료별 **사용량 × 단위 단가**), 필요 시 수율 반영.

### 수율(폐기율) 개념

손질 과정에서 껍질·뼈·심지 등이 버려지므로, 실제 필요한 구매량은 사용량보다 많습니다.

```
실구매 필요량 = 사용량 ÷ 수율
재료 원가 = (사용량 ÷ 수율) × 단위 단가
```

예: 대파 사용량 20g, 수율 90% → 실제 22.2g 구매분의 원가로 계산

참고: [한성쇼케이스 — 폐기율 계산](https://blog.hansungshowcase.kr/92236), [식품영양 위키 — 발주량 산출](https://nutri.fandom.com/ko/wiki/%EB%B0%9C%EC%A3%BC%EB%9F%89_%EC%82%B0%EC%B6%9C)

### 단가 기준 — 어떤 가격을 쓸 것인가

회계상 재고자산 평가 방법이 여럿 있고, 어떤 단가를 쓰느냐에 따라 원가율이 달라집니다:

| 방식 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **최신 입고가** (최종매입원가) | 가장 최근 입고 단가 적용 | 단순, 시세 변동 즉시 반영, 실무 직관적 | 일시적 급등이 과대 반영될 수 있음 |
| 이동평균 | 입고할 때마다 평균 단가 갱신 | 변동이 완만 | 시세 반영 느림 |
| 선입선출(FIFO) | 먼저 산 로트부터 소진 가정 | 회계적으로 정확 | 로트 추적 필요 — 음식점 실무에 과함 |

**결정: 최신 입고가 기준 (사용자 요구사항)** — "지금 이 재료를 다시 사면 얼마인가"를 반영하므로 가격 인상기에 경고가 빨리 뜨는 장점이 있음. 이동평균은 추후 참고 지표 옵션으로 검토.

참고: [Channel-JS — 재고자산 단위원가 비교](https://channeljs.com/entry/%EC%9D%B4%EB%8F%99%ED%8F%89%EA%B7%A0%EB%B2%95%EC%B4%9D%ED%8F%89%EA%B7%A0%EB%B2%95%EC%84%A0%EC%9E%85%EC%84%A0%EC%B6%9C%EB%B2%95%EC%9E%AC%EA%B3%A0%EC%9E%90%EC%82%B0%EB%8B%A8%EC%9C%84%EC%9B%90%EA%B0%80/), [BoxHero — 재고 단가 결정](https://www.boxhero.io/ko/blog/jaego-jasanyi-suryang-gyeoljeonggwa-danga-gyeoljeong-bangbeob)

## 3. 계산 예시

### 예시 1: 김치찌개 (판매가 9,000원)

| 재료 | 사용량 | 최신 입고 단가 | 수율 | 재료 원가 |
|------|--------|----------------|------|-----------|
| 돼지고기 앞다리 | 120g | 12,000원/kg | 95% | 1,516원 |
| 묵은지 | 180g | 3,500원/kg | 100% | 630원 |
| 두부 | 1/3모 | 1,050원/모 | 100% | 350원 |
| 대파·양파·마늘 | 60g | 2,500원/kg | 90% | 167원 |
| 고춧가루·장류 양념 | 15g | 10,000원/kg | 100% | 150원 |
| 공기밥 + 기본 반찬 (공통재료 배부) | 1식 | — | — | 400원 |
| **합계** | | | | **3,213원** |

```
원가율 = 3,213 ÷ 9,000 × 100 = 35.7%   → 적정 구간(30~40%) 내
```

판매가 역산 활용: 목표 원가율을 33%로 낮추고 싶다면
→ 판매가 = 3,213 ÷ 0.33 ≈ 9,736원 → **9,800원 또는 10,000원으로 조정 검토**

돼지고기 입고가가 12,000 → 15,000원/kg로 오르면:
→ 돼지고기 원가 1,516 → 1,895원, 합계 3,592원, **원가율 39.9%** → 시스템이 경고 표시

### 예시 2: 병맥주 (개수 품목)

```
최신 입고가 1,800원/병, 판매가 5,000원
원가율 = 1,800 ÷ 5,000 = 36%
```
개수 품목은 수율·레시피 없이 입고 단가가 곧 원가 → 계산 단순.

### 부가세 주의사항

판매가 9,000원이 **부가세 포함**이면 실제 매출(공급가액)은 8,182원:

```
공급가액 기준 원가율 = 3,213 ÷ 8,182 = 39.3%   (표시 원가율 35.7%와 차이 큼)
```

원가율을 어느 기준으로 표시할지(판매가 vs 공급가액)는 시스템 설정으로 결정 필요 → TBD.
보수적 관리를 원하면 공급가액 기준 권장.

## 4. 이론 원가율 vs 실제 원가율

우리 시스템의 재고 정책(레시피 사용량 = 참고값, 일일 마감 수동 차감)과 자연스럽게 연결되는 개념:

| 구분 | 계산 | 의미 |
|------|------|------|
| **이론 원가율** | 레시피 사용량 × 최신 단가 ÷ 판매가 | "레시피대로 만들면" 나와야 하는 원가율 |
| **실제 원가율** | 기간 실제 재료 사용액(입고-재고 증감) ÷ 기간 매출 | 실제로 쓴 비용 기준 |

**이론 vs 실제의 차이 = 로스(과다 사용, 폐기, 누락, 도난 등)** — 두 값을 나란히 보여주는 것이 원가 관리의 핵심 기능. 차이가 크면 주방 운영 점검 신호.

## 5. 운영비 / 손익 관리

### 비용 분류 (국내 외식업 통용)

| 분류 | 항목 |
|------|------|
| **고정비** | 임차료(월세), 정규 인건비, 4대보험, 감가상각, 통신·구독료, 보험 |
| **변동비** | 식재료비, 포장재, 결제 수수료, 배달 수수료, 수도광열비, 소모품 |

- 인건비 비율: 매출 대비 20~30%가 일반적
- **프라임 코스트**(식재료비 + 인건비): 매출의 60~65% 이내 관리가 널리 인용되는 기준

### 손익분기점(BEP)

```
손익분기 매출 = 고정비 ÷ 공헌이익률     (공헌이익률 = 1 − 변동비율)
```

**예시**: 월 고정비 1,200만원 (월세 250 + 정규 인건비 800 + 보험·통신 등 150), 변동비율 41% (식재료 35% + 결제 수수료 1% + 수도광열·소모품 5%)

```
공헌이익률 = 1 − 0.41 = 0.59
손익분기 매출 = 1,200만 ÷ 0.59 ≈ 월 2,034만원  (30일 기준 일 약 68만원)
```

월 매출 3,000만원 달성 시:
```
영업이익 = 3,000만 − (3,000만 × 0.41) − 1,200만 = 570만원  (영업이익률 19%)
```

## 6. 시스템 기능 매핑 (제안)

```
입고 등록 (FR-05)
  → 품목별 최신 입고 단가 자동 갱신
레시피 (FR-03)
  → 재료별 사용량 (+수율 선택 입력)
원가 엔진 (FR-10)
  → 메뉴별 원가·원가율 자동 계산
  → 단가 변동 시 전체 메뉴 원가율 자동 재계산
  → 원가율 임계치(가게 설정, 예: 40%) 초과 메뉴 경고
운영비 관리 (FR-10)
  → 고정비 항목 등록(월세 등) + 인건비(FR-06 근무기록 연동) + 변동비 자동 집계
  → 월 손익 리포트: 매출 − 재료비 − 인건비 − 고정비 = 영업이익
  → 손익분기점 표시 + 이번 달 진행률
```
