# ProjectSMS 기획 문서

일반 음식점을 대상으로 하는 범용 관리 시스템(SaaS) 기획 문서 모음입니다. 코드 구현 전에 **아이디어를 탄탄히 정리하고 단계별 계획**을 세우기 위한 문서 세트입니다.

## 문서 읽는 순서

1. **[00-overview.md](./00-overview.md)** — 프로젝트 개요, 비전, 용어집
2. **[01-requirements.md](./01-requirements.md)** — 기능/비기능 요구사항
3. **[02-user-roles.md](./02-user-roles.md)** — 사용자 역할과 권한 매트릭스
4. **[03-features/](./03-features/)** — 기능별 상세 기획 (12개 문서)
5. **[04-architecture.md](./04-architecture.md)** — 시스템 아키텍처 초안
6. **[05-data-model.md](./05-data-model.md)** — 데이터 모델 초안
7. **[06-roadmap.md](./06-roadmap.md)** — 단계별 개발 로드맵
8. **[07-open-questions.md](./07-open-questions.md)** — 아직 결정되지 않은 사항
9. **[08-workflow-diagrams.md](./08-workflow-diagrams.md)** — 업무 워크플로우 다이어그램 (비개발자 관점)
10. **[research/](./research/)** — 미정 사항 의사결정용 시장/기술 조사 (하드웨어, 결제 연동)

## 문서 작성 원칙

- **초안 우선**: 먼저 빠르게 초안을 만들고, 대화를 통해 반복 보완합니다.
- **유연성**: 음식점마다 운영 방식이 다르므로, 기능은 가게별로 커스텀 가능하도록 설계합니다.
- **단계별 확장**: MVP → 기능 확장 순으로 로드맵을 따릅니다.
- **미정 사항 추적**: 결정되지 않은 항목은 모두 `07-open-questions.md`에 기록합니다.
